### 2.3 受控冒烟（账目口径验证）

闭合域 40×40 @ 50 m，均匀雨 36 mm/h × 1 h，无 bci。
产物：`outputs/bench/B9_loss_smoke/`（自带 `meta.json`，标 `not_physical_recalculation=true`）。

| 项 | 实测 | 解析期望 | 误差 |
|---|---|---|---|
| 无入渗档净雨列 | 144,000 m³ = 36.0 mm | 36.0 mm | 0 |
| 无入渗档蓄量 | 144,000 m³ = 36.0 mm | 36.0 mm | 0（**逐位相等**） |
| 入渗 5e-6 m/s 档净雨列 | 74,000 m³ = 18.5 mm | 18.5 mm | 0 |
| **反算损失** | **70,000 m³ = 17.5 mm** | **17.5 mm** | **0.000** |
| 四边通量 | Qin = Qout = 0 | 0 | — |
| **判定** | **PASS** | | |

解析修正说明：`FPInfiltration` 有 `H>1e-3 m` 门限，36 mm/h 下前 100 s 不扣水，
故解析损失是 17.5 mm 而非朴素值 18.0 mm。判据用含门限值，两值都报。

**已登记但不作门的观察**：`.wd` 末帧平均水深 18.0 mm，比质量列反算的 18.5 mm 低 0.5 mm。
`write_solution`（`swe/output.cpp:111`）与 `write_mass_stats`（`fv1.cpp:70-72`）同循环顺序触发，
快照滞后一步；一步入渗仅 0.025 mm，不足以解释 0.5 mm → **差异来自快照滞后，不是账目错误**。
久隆账目全部基于 `res.mass`，不依赖 `.wd` 场，故不影响结论。

→ **账目口径由此升为 E1**。

## 3. Phase 4：边界与重复计量核查

### 3.1 边界结构（E1）

`bci.bci` 现状：`N`/`W`/`E` 三边 `FREE`（未给坡度），`S` 边 `FREE 0.0005`。

**本构建的记账结构（源码核验）**：
`BoundaryFlux()`（`boundary.cpp:1327-1409`）把四边通量按正负分别累加，
最后合成**单个** `BCptr->Qin` / `BCptr->Qout`。`res.mass` 的 Qin/Qout 列**只有域总账，
没有逐边账目**。无 chanmask 时 `ChanMask` 全为 -1（`input.cpp:1459`），四边全部参与记账。

→ **逐边份额无法从 `res.mass` 取得**。本节逐边数字是**估计值（E4）**，不是求解器记录值。

FREE 边界在 sign 钳位下只能出流不能入流（`boundary.cpp:180-183`），
故 `Qin ≡ 0` 与边界设置自洽。

### 3.2 逐边估计（E4，53 帧）

### 3.4 东缘高地排水口（**本次审计重点发现**，E3）

逐单元热点定位（累计估计通量占该边 ≥5% 的单元）：

| 边 | 热点数 | 代表热点 |
|---|---|---|
| N | 6 | cell 109，DEM 1.2 m，均水深 0.048 m |
| S | 0（通量分散） | — |
| W | 2 | cell 37，DEM 9.61 m，均水深 0.012 m |
| **E** | **4** | **cell 21，DEM 23.35 m，均水深 0.014 m；cell 20，DEM 23.01 m，均水深 0.007 m** |

东缘出流的 **97%** 来自 DEM>5 m 的高地单元，热点位于 22.2–23.4 m、平均水深仅 0.007–0.022 m。
这些单元不是真实排水出口，而是**边界被当作人工排水口**排走高地薄膜水。

**与宁明 D4 的关系**：属**同类问题**（边界可自由排水且与地形/汇流关系未核证），
但**成因不同**：D4 是注入口与出流边界重合（83.0% 注入量从东缘排走），
本例是全域无注入、仅靠四边缓排，且量级小（E 边占估计总出流 12%）。

**方向性后果**：假排水让模型显得比实际更能退水；而真实退水仍严重不足（见 §4）。
两项误差方向相反，不能相互抵消，必须分别登记。

**候选处置（仅候选，未执行）**：
1. 将 N/W/E 改为闭合，只留南缘 `FREE 0.0005`，作为新 run tag 单独试验；
2. 或保留 N/W/E 但只在 DEM 低地边缘段开 FREE（需 D4 资料支撑）。
**不得**直接修改现有 `bci.bci`（会污染已冻结基线）。

仅在 7→8、10→11 两日出现"出流 > 蓄量占比"的短暂退水，其余 11 日蓄量占比均 >41%，
且从未出现蓄量净减少超过降雨的时段 → **模型在整个延长段持续积水，从未进入真正退水**。

## 5. 可写 / 不可写

### 5.1 可写

- 三档预注册敏感性情景**已登记**（跑前冻结 + 哈希校验），B 档 0/1e-6/5e-6/1e-5 m/s，C 档 Ia 5/15/30 mm、fc 1/3/6 mm·h⁻¹；**不构成率定**。
- 账目口径经闭合域受控算例验证（36 mm/h 雨 + 18 mm/h 入渗 → 反算损失 17.5 mm，误差 0.000）→ **E1**。
- 13 天水量账目：总雨 2.6834e8 m³、出流 3.3787e7 m³（12.6%）、蓄量增 2.3441e8 m³（87.4%）、残差 −0.053%，E_mass 5.3e-4 **PASS**。
- 边界结构：四边均 FREE（S 带 0.0005 坡度），本构建**无逐边 Qin/Qout 账目**（`boundary.cpp:1327-1409`）。
- **无 D4 式注入短路**（Qin ≡ 0）；但**存在三边可出流的结构风险**，东缘 97% 出流来自高地单元（DEM 22.2–23.4 m、水深 0.007–0.022 m）。
- 退水异常**未消除**：出流能力仅为维持蓄量所需的 12.6%–17.9%，原因是无排水网络 + 边界排水不足 + 延长段仍有 84 mm 降雨 + 无蒸发无入渗。

### 5.2 不可写

- 不得把任一档写成率定值、推荐值或「最优参数」——久隆无连续水位/流量过程，无 CSI/NSE 独立门。
- 不得写「质量门全量通过」——久隆仍有 FAIL-EXPLAINED run（z05/z10/ztide），不计通过。
- 不得把 C 档写成「已跑初损模型」——本构建无初损参数，它只是雨量序列预处理候选。
- 不得把 B 档上界（尤其 5e-6/1e-5）当作实际损失量——上界已超总雨量，物理上不可实现。
- 不得把逐边份额写成求解器实测值（E4 估计，比值 0.87）。
- 不得把 D8 廊道当作真实沟渠，不得据此刻蚀河道，不得声称排水网络已建成/已治理。
- 不得用滤波或平滑掩盖退水异常。
- 不得给出绝对高程/资产级水深结论（G7 垂直基准未闭合）。
