# ADR-0015：学术借鉴与改进产品口径（FAT / 成因归因 / 概率产品预注册）

- **状态**：已接受（Accepted）。计划即授权：`plans/广西二维水动力模拟_学术成果驱动改进实现计划.md` §5.3 run 清单经用户 2026-11-22 批准。
- **日期**：2026-11-22
- **触发**：质量门 61 PASS / 3 FAIL-EXPLAINED / 0 FAIL（64 run）已达水量闭合受控；预测性验证与驱动链五短板（P1–P5）需产品化。两位教授成果（`教授交流/教授检索详情.txt`）提供方法来源。

## 决策

### 1. 产品落盘目录决议

| 产品 | 落盘位置 | 审计件（`data/catalog/`） |
|---|---|---|
| FAT / 超阈时间 | `outputs/products/<site>/fat/<run_id>/`（first_wet_h.tif、exceed_h_thr0p3/0p5/1p0.tif、duration_h_thr0p3/0p5/1p0.tif） | `fat_products_audit.json` |
| 站点级超阈时间表 + 暴露三元组 | `outputs/products/<site>/fat/station_tables/`（CSV + JSON） | 同上 |
| 成因归因 | `outputs/products/guigang/genesis/<run_id>/`（origin_class.tif） | `guigang_genesis_rules.json`（规则先冻结后计算） |
| 集合超越概率 | `outputs/products/ningming/probability/`（exceedance_probability_thr*.tif） | `ningming_probability.json` |
| GR4J 边界件 | 新 run 目录内 `inflow_guigang.bdy` / `inflow_ningming.bdy` | `guigang_inflow_priors.json` + `inflow_audit.json` |
| 基准核证 | — | `gx_datum_probe.json` |
| Copula / MMF | — | `copula_thresholds_report.json`、`mmf_rainfall_evaluation.json` |

- 派生层目录不得含 `res.mass`（g15 复算误计防线）；新产品命名沿用 `products/` 体系，展示层沿用 `display_qc` 纪律。
- 审计件带 E1–E4 证据等级、`generated_utc`、输入哈希与显式「未验证」字段。

### 2. FAT/超阈时间产品口径（钟鸣 FAT 思想降级）

- **首湿时刻**：像元首次 wd>0.05 m 的模型时刻（h）；全程不湿记 NA（-9999）。
- **超阈时刻**：首次 wd>情景阈值；**超阈历时**：累计超阈帧时数。
- 情景阈值 0.3/0.5/1.0 m 三档，独立成件；**禁止称设备安全值**（无业务授权数据）。
- 帧时基：seq × saveint（run.par 校验，`grid_io.frame_timeline`）。
- 站点表：站址像元 ±2 格（ADR-0006）；站址像元未湿时报 NA 并附最近湿像元距离（格）与该像元首湿时刻（久隆站址 0.008 m 先例）。
- 三级窗：<6 h / 6–24 h / >24 h 分组展示，**标注「研究性分组，非应急等级」**。
- 覆盖：三地全部质量门 PASS run（61 run，以 `mass_recheck_g15.json` 为权威）；非 PASS run 不产出 FAT 产品。

### 3. 成因归因产品口径（吴欢 DRIVE-Urban 思想降级）

- 规则（event-max 湿像元集合 = full run `res.max`>0.05）：
  - full 湿 ∧ rain_off 湿 → 1 river-origin；
  - full 湿 ∧ rain_off 干 → 2 pluvial-origin；
  - full 干 ∧ rain_off 湿 → 4 disagreement（水量再分配，单独统计，不计入任一成因）；
  - 两者皆干 → 0 never-wet；域边界 1 格环带 → 3 edge-band 单独标记。
- 规则 JSON **先冻结后计算**（`guigang_genesis_rules.json`），冻结后不得回改；改规则须新 ADR。
- 对照对：`chhyd_d14_r4_infil3`（full，锚点）× `chhyd_d10_r2_norain`（rain_off）。**已注册混淆项**：两 run 河槽配置不同（d14 vs d10），归因结论须随附此 caveat；不得称「外洪/内涝精确分解」，只称「有雨/无雨情景差分归因」。

### 4. 概率产品口径（P5，宁明集合先行）

- 逐像元超越概率 P(wet|ensemble) = 集合中 wd>阈值的成员占比；float32 0–1。
- 成员清单强制入审计 JSON：run 标识、质量门状态、参数档；非 PASS run 禁入集合。
- Copula 联合阈值：变量 = 区域年最大 3 日雨量（ERA5 长序列）× 事件前 30 日湿度代理；Gaussian/Clayton/t 三族 AIC 选优；**统计阈值仅作情景设计参考，禁业务告警（ADR-0004 红线）**；样本不足用信息扩散 + Bootstrap；拟合失败如实记「未验证」。
- 依赖策略：sdv-dev Copulas 许可证 NOASSERTION 未复核前不引入；先用纯 numpy 手写三族拟合（约 200 行），行为可测。

### 5. 边界件与授权 run 纪律

- GR4J bdy 只写**新建** run 目录；`guard_no_overwrite` 前置 + `run_manifest` 留痕。
- 5.3 授权清单（5 run）：贵港 `scen_gr4j_q_100m` / `scen_zdown_a_100m` / `scen_zdown_b_100m` / `scen_imerg_ga_100m`；宁明 `scen_gr4j_q6000_100m`。清单外 run 仍须单独批准。
- 任一授权 run 落质量门 FAIL 即停线排查；HVAR 下游水位情景按 FAIL-EXPLAINED 口径预注册（G13 先例）。

### 6. 数据不可得降级（计划 §6.4）

- IMERG（Earthdata 凭证）、GloFAS（CDS key）、ATL13（NSIDC 凭证）任一不可得：对应任务记「数据不可得」，不留半成品；S3/S4/S5 记「未验证」；脚本与单测仍落地（合成数据），获取侧等待凭证。

## 后果

- **正面**：P0 级产品（FAT/归因/暴露/概率）零重跑即可产出（E2/E3 级）；上游来水与多源降雨进入预注册流程；G7 获得「有界估计」路径。
- **限制**：全部新产品维持情景级/研究性标注；归因受 d14/d10 河槽差异混淆；Copula 为探索性；S3/S4/S5 依赖外部数据凭证，当前按「未验证」登记。
- **禁止表述**：FAT 三级窗不得称应急等级；归因不得称精确成因分解；概率/Copula 阈值不得用于业务告警；ATL13 offset 不得写死 datum_offset 常数。
