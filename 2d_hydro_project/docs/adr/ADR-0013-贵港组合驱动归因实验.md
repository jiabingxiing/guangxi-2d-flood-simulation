# ADR-0013：贵港组合驱动归因实验（hydraulic 河槽 × 净雨）

- **状态**：已接受（Accepted）。用户 2026-11-07 批准 3 个组合 run 重跑 lisflood.exe；净雨机制采用「GA-Mid 物理净雨为主 + Ia/fc 标量对照」。
- **日期**：2026-11-07
- **触发**：ADR-0012 首轮实测否证了「河槽几何改善 S1 FAR」的预期（FAR 0.919~0.930 vs 基线 0.921；POD 0.652→0.403 单调下降）。同表证据把假警报主导因素定位到**滩地降雨积水**（`flow_only_v1` 无降雨输入 FAR 0.817，Δ−11.3%，而任何河槽几何情景 |ΔFAR|≤1%）。第二轮用 2×2 因子补全 + 物理净雨，把河槽效应、降雨效应与交互项定量分开。

## 背景

1. **首轮结果（E1，`guigang_s1_validation.json`，t=228 h 足迹内口径）**：五深度情景 CSI 全部低于基线（0.063~0.074 vs 0.076）、FAR 压降 >20% 全部未达成。河槽输水本身有效（足迹内模拟水 92.63→65~67 km²，−28%），但排走的水同落命中与虚警区，POD 单调损失。
2. **预处理器资产就绪**：Phase G 的 `rainfall_runoff_preprocessor` 案例无关，贵港产物已生成（`outputs/preprocessor/guigang/`，GA-Mid 净雨 38.93 mm / 毛雨 137.1 mm，−71.6%）；久隆 GA v1 已验证「路径 A（净雨 .rain）」入模方式（`run_jiulong_ga_rerun.py`，run.par 仅 `rainfall` 行，`E_mass` PASS）。
3. **工程事实**：分布式入渗 `infilfile`（pars.cpp:492）在本构建 acceleration 求解路径不生效（`infevap.cpp` 只用标量 `InfilRate`；known_limit 已登记 `configs/model_manifest.yaml`）→ 本实验全部走路径 A，run.par **不写** `infiltration`/`infilfile`（ADR-0011 决策 2 不混用纪律）。
4. **时基口径（贵港特有，久隆无此问题）**：ERA5 probe 首键 2024-09-05T00，模型 T0=2024-09-03T00 → 预处理器净雨时轴须 **+48 h 显式移位**；probe 序列 312 h，模拟窗 336 h，尾段（09-17T01..23，毛雨 1.6 mm / GA 净雨 0.06 mm）按窗口裁剪。G1 对账已实测：`rainfall_gross.rain` 与 probe 逐值一致，summary 的 137.1 mm 为全序列口径，与 E1 的 135.50 mm 之差 = 窗口裁剪，非数据缺陷。

## 决策

### 1. 组合矩阵（预注册 `guigang-round2-combo-v1`）

| 角点 | 河槽 | 降雨 | 状态 |
|---|---|---|---|
| baseline_realdem | off | on | 已有（FAR 0.921） |
| flow_only_v1 | off | off | 已有（0.817） |
| dualloss_v1 | off | loss_medium | 已有（0.901） |
| rainloss_high_v1 | off | loss_high | 已有（0.899） |
| chhyd_d10 / d12 / d14 / d16 / d19 | hydraulic | on | 已有（0.919~0.930） |
| **chhyd_d14_r2_lossmed** | hydraulic d14 | loss_medium | **本轮新跑** |
| **chhyd_d14_r2_ga** | hydraulic d14 | **ga（GA-Mid）** | **本轮新跑（主方案）** |
| **chhyd_d10_r2_norain** | hydraulic d10 | off | **本轮新跑** |

### 2. 归因方法

2×2 因子差分（河槽主效应、降雨主效应、交互项），作用指标：足迹内模拟面积、FAR、POD、CSI、帧湿格数。实现为只读脚本 `scripts/stage6/attribute_guigang_combo.py`，输入 `guigang_s1_validation.json`，输出 `data/catalog/guigang_combo_attribution.json`。

### 3. 方向性预期（预注册，无硬门）

- 组合情景 FAR < min(单机制 FAR) = 0.901；
- `chhyd_d10_r2_norain` FAR < `flow_only_v1` 的 0.817；
- 若未达：如实登记，下一误差源候选 = DEM 高程基准（G7）/ 堤防缺失 / S1 阈值与足迹口径（G17）。

### 4. 禁止表述清单

- 不得把组合情景写成「校准」或「修复」；GA-Mid 的前期土壤水分取 mid 情景假设，未经实测核验。
- 不得把 CSI/POD/FAR 写成模型精度；只表述为足迹内重叠度。
- 不得在归因 JSON 落盘前引用任何「组合优于单机制」的结论。
- 不得称 GA 净雨为「实测入渗」；它是区域先验合成土壤参数（`south_china_alluvial_red_soil`）上的模型净雨。

## 后果

- **正面**：把「降雨积水」假设变成可差分验证的因子实验；GA 物理净雨首次进入贵港 run 链。
- **限制**：depth 仅 d10/d14 两档；GA 空间均匀时序（无空间入渗差异入模）；GA-Dry/Wet 前期水分情景与更深层位留待后续。
- **风险控制**：+48 h 时基移位由 `scripts/common/net_rain.py` 显式实现并以单元测试锁定（首键校验、端点补零、单调性拒绝）。
