# ADR-0007：执行状态与降级边界

- **状态**：已接受（Accepted）
- **日期**：2026-10-26
- **触发**：需要明确“首轮情景已跑”与“终稿计划完成”的区别，防止把降级结果当业务系统。

## 决策

1. 当前状态记为 **stage 3–5 degraded**；阶段 0 原门禁未满足，阶段 6 未执行。README、配置 `implementation`、`docs/execution_status.md` 均按此表述。
2. 实际分辨率：久隆 200 m、宁明 100 m、贵港 200 m 走廊；计划 12.5/25/30 m 与 5 m 局部未执行。配置保留计划值，另列 `implementation.resolution_m`，不得混用。
3. 贵港 30 m 全域、区域—局部 5 m 单向接口、在线预报/R10 均列为阻塞/推迟，不宣称完成。
4. 授权 Q(t)/Z(t)/雨量/潮位、G7 基准、G12 坐标、站区资产、RACI、许可未到位前，成果不得外发为业务结论。
5. 代码暂不自动提交 git（用户未授权）；以 `code_manifest.json` 树哈希作为版本记录；用户授权后可补 commit。

## 后果

- 报告/README 统一写“降级模式、情景级、部分完成”；删除“三案例全部闭环/质量门通过/B1–B7 全部通过”。
- Phase B（空间 Manning、敏感性、结构、喀斯特、产品补全）和 Phase C（用户数据）分开跟踪。
