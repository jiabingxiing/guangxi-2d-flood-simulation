# ADR-0020：久隆钦江河道亚网格表达与河道—洪泛区耦合（SGC + 四道护栏）

- **状态**：已接受（Accepted）；SGC 最终启用以 3 项小算例核验结论为准（进行中，见执行状态）。
- **日期**：2026-11-22
- **触发**：200 m 网格远宽于钦江窄河槽（S1 常水 100 m），纯雨基线无法表达河道输水；直接刻槽有宁明 244.2 m 全判 FAIL 与贵港 19 m 深槽 POD 滑坡 0.403 的前车之鉴。
- **关联**：ADR-0010（久隆治理规范）、ADR-0012（贵港河槽重构经验）、ADR-0019（Q(t) 输入）。

## 背景（能力核验，2026-11-22 实测）

1. 本地 `lisflood.exe`（models/lisflood-fp-8.1/LISFLOOD-FP-trunk）**源码含 SGC**（sgc.cpp/sgm_fast.cpp），二进制 strings 含 subgrid（4 处）→ 编译启用，待小算例实测确认。
2. SGC 输入接口（pars.cpp/sgc.cpp 源码核对）：`SGC_enable`（空参数，连带强制 acceleration、关 adaptive_ts/qlim）、`SGCwidth`/`SGCbank`（ASCII 栅格，6 行头，逐格读取）、`SGCchan 1`（矩形）、`SGCn`、水力几何 depth=r·w^p（`SGCr`/`SGCp`）；`SGCdirnfile` 缺省可跳过（input.cpp:971）。
3. 河网数据链降级记录：OSM 主站与镜像全部不可达 → **用户当日提供本地全量抽取**（china-261121.osm.pbf，1.6 GB）→ pyosmium 提取 AOI 缓冲框 318 条水系、钦江 12 段。HydroRIVERS MAIN_RIV=41134077 含全水系支流，干流须沿 NEXT_DOWN 链提取（24 段）。

## 决策

1. **河道表达首选 SGC 亚网格（方案 A）**：`sgc_width.asc`（宽 140 m = S1 常水中位 100 m × 满槽因子 1.4 先验，硬上限 180 m < 200 m 格）+ `sgc_bank.asc`（DEM 原值，不改写地形）；床面由水力几何 depth=r·w^p（r=0.612, p=0.4 → 满槽深 ~4.5 m，E3 先验，无实测断面）。**不生成刻蚀 DEM**。
2. **中心线（护栏 2 达成）**：OSM 干流（12 段，纬度定向）优先，HydroRIVERS NEXT_DOWN 链回退；S1 2024-09-05 常水核验重合率 0.31（门限 ≥0.12 格水面占比）；OSM↔HydroRIVERS cell Jaccard 0.17（概括尺度差异，记录不判 fail）。入域断面 (0,156)（N 缘）与出海口 (151,26)（S 缘）对齐；8 邻域 0 断裂。
3. **护栏 1（必跑 R2a）**：原地形无刻槽 + 纯 QVAR 对照 run 是 R2/R3 的前置对照，用于量化「无河槽时来水摊散」的基准形态。
4. **护栏 3（基流 S1 体检）**：R2（rain off + QVAR）兼作常水体检：基流不得漫滩、洪峰（R3）能漫滩；不合格时先查连通与入流位置（宁明 D4 教训），不调糙率。
5. **护栏 4（向 SGC 演进）**：水利部门实测大断面取得后，河宽/床高转为逐格 SGC 属性（或 SGCbed 文件），永久免去地形改写。
6. **浅槽备选（方案 C 降级）仅在 SGC 小算例核验失败后启动**：2–5 m 限幅 + `Z_new=min(Z_orig, Z_ideal)` + `max_cut ≤ D+2 m` 硬门禁，另行建流程，不在本 ADR 内预生成。

## 已知限制（如实登记）

- 200 m 格内中心线 cell 沿线 DEM 存在局部倒坡（max 8.4 m，17.7% 格 >0.5 m）：亚像元河槽跨格取样的固有限制，影响局部输水节奏，不做 DEM 改写掩饰；实测断面接入后消除。
- 支流：AOI 相交结果 CATCH_SKM≥20 km² 无命中（HydroRIVERS 口径），v1 不设支流 QVAR；排埠江级支流以域内净雨近似，限制登记于 `jiulong_hydrography.json.uncertainties`。

## 验收方法

- SGC 三项小算例（输水/漫溢/退水，`run_sgc_synthetic_tests.py`）全 PASS 且 E_mass ≤1e-3；R2 基流不漫滩；R3 沿江漫滩且非河道碎斑相对 R1 下降；`channel_geometry_audit.json` 拓扑 6 项连续性/对齐项 PASS（单调项按已知限制记录）。

## 不适用条件与回滚

- SGC 小算例失败 → 护栏 6 浅槽流程接管（新 ADR 记录）；OSM 数据更新或水利资料到位 → 中心线版本化重建（新 run tag，不覆盖）。
