# ADR-0014：贵港排水连通治理（仅 DEM 可用 · 诊断探针）

- **状态**：已接受（Accepted）。用户 2026-11-07 批准 3 个治理 run；定位为**诊断探针**。
- **日期**：2026-11-07
- **触发**：ADR-0013 组合归因定位残余 FAR 结构——上游输水已由重构河槽解决（无雨角点 FAR 0.386），**残余假警报主体是净雨滩地积水**（有雨运行点 FAR ~0.90；净雨预处理只裁掉毛雨 1/3，天花板已见）。用户约束：只有 DEM，无排水网资料。

## 背景

1. **预处理器排不掉积水（定量）**：贵港 GA 土壤有效深度 1.0 m、Δθ≈0.13-0.14 → 蓄水容量 F_cap≈130-140 mm ≥ 全场毛雨 137.1 mm，土柱事件内不饱和 → `green_ampt_net_rain` 的 `drainage_mm_h`（饱和后才生效）永不触发；且预处理器只处理降雨序列，无法作用于已进入求解器的积水。**垂直排水只能由求解器承担**。
2. **求解器入渗可用（源码实证）**：标量 `infiltration` → `Parptr->InfilRate`（pars.cpp:484-487），FPInfiltration（infevap.cpp:14-46）对 H>1e-3 m 湿格持续扣水；贵港 22 个 run.par 从未使用。**路径 B 单用**（毛雨 + 求解器入渗）与净雨预处理（路径 A）混用会重复扣损（ADR-0011 决策 2）——本轮路径 B 单独成情景，run.par 不写净雨类关键字。
3. **水平排水的合法性前提已变**：ADR-0011 决策 3 的「D8 三版失败、获高精度 DEM 前不应重试」针对**无槽 DEM 上找主槽**（平原无全球汇）。ADR-0012 刻槽后主槽（床高 6~20 m）成为全球汇，priority-flood + D8 汇流线推导在**已刻槽 DEM** 上重新成立。这不是对旧结论的重试，而是前提变更后的新推导；沟位仍只由 DEM 推导，模型积水只做诊断不用于布沟（循环论证隔离）。
4. **分辨率硬约束**：100 m 格上 30 m 级沟的格元平均下切仅 0.1~0.3 m，无水力意义；排水沟必须 ≥1 格宽（100 m）。

## 决策

### 1. 治理矩阵（预注册 `guigang-round3-drainage-v1`）

| run | 河槽 | 排水沟 | 入渗 | 降雨 |
|---|---|---|---|---|
| chhyd_d14（锚点） | d14 | — | — | 毛雨 |
| chhyd_d14_r3_infil2 | d14 | — | 2.0 mm/h | 毛雨 |
| chhyd_d14_r3_drA | d14 | **A 档** | — | 毛雨 |
| chhyd_d14_r3_combo | d14 | A 档 | 2.0 mm/h | 毛雨 |

A 档沟参数：宽 100 m（1 格）、深 2.0 m、汇流阈值 200 格（2 km²）、最小沟长 2 km、沟间距 ≥1 km；沟床 = 沿线平滑地表 − 2.0 m，顺流单调；沟只向主槽排（主槽格为 priority-flood 种子）。

### 2. 诊断探针定位（核心纪律）

DEM 推导排水沟与求解器入渗都是**情景假设**：目的是量化「多强的排水能力能解释残余 FAR」，**不是声称真实排水网长这样**。沟位/沟距/沟深/入渗率无任何实测资料校验；成果必须随附探针声明；不得用于资产判据、业务预警或「排水工程设计依据」。

### 3. 方向性预期（预注册，无硬门）

- r3_infil2 与 r3_drA 的 FAR < chhyd_d14 的 0.925；r3_combo 最低；
- 若不达：如实登记并结论化为「滩地积水对排水不敏感，残余 FAR 另有主因（DEM 高程基准 G7 / 堤防缺失 / S1 阈值与足迹口径 G17）」。

### 4. 禁止表述清单

- 不得称 DEM 推导沟为「排水网络重建」「真实排涝通道」或「工程设计方案」。
- 不得把 r3 情景的 FAR 变化写成「治理成效」——是探针差分，不是工程验收。
- 不得在无排水网资料时虚构沟位依据；沟的一切参数登记为情景假设。
- 入渗率恒定无土壤库，事件后期可能过排；速率受红壤 fc 2~3 mm/h 先验上限约束，不得外推为「入渗能力已率定」。

## 后果

- **正面**：把「积水需要多少排水能力」变成可差分实测的量；垂直/水平两条排水路径的贡献首次分离。
- **限制**：100 m 格元平均近似；A 档保守起步，B 档（更密/更深）留待 A 档结论；诊断 JSON 与探针声明随成果强制出现。
