# ADR-0022：久隆 2024 历史工况时空一致性与海陆/潮位边界物理化

- **状态**：已接受（Accepted）。
- **日期**：2026-11-22
- **触发**：平陆运河 2026-06 通水、2026-09 通航；久隆站（K88+000）2026-11-22 水位 8.98 m（85 高程）属通航后工况。2024-09 摩羯情景**严禁**混用 2026 运河地形/水位。
- **关联**：ADR-0017（ATL13 垂直基准探针）、ADR-0010（G7/G13 边界教训）、ADR-0019/0020。

## 决策

1. **历史工况档案（2024-09-yagi 专属）**：地形 = 既有 200 m 生产基线 dem.asc（BFS 填负值 + 海钳零口径冻结，12.5 m 源 DEM 可追溯）；河道 = OSM 2026-11 抽取（运河施工对钦江干流河道改动的矢量证据未见，中心线按现状记录并标注「2024 河道格局以水利档案复核为准」）；平陆运河施工工况（2024-09 尚未通水）作为独立不确定性条目登记，不引入 2026 断面。
2. **边界重构（计划 §七）**：N 缘 = QVAR（入域断面 col≈156，段宽 3 格）；S 缘 = FREE 0.0005（R1–R3）/ HVAR qztide（R4，沿用零相位合成潮包络口径）；**E/W 缘闭合**（分水岭），消除基线四边 FREE 的东缘 97% 高地假排水；G13 激波教训 → HVAR 仅作用于河口深槽单元、前 24 h 线性缓升在 R4 以后版本接入（本版合成潮沿用既有序列，实测 E_mass 判定）。
3. **G7（垂直基准）**：维持 ADR-0017「未闭合」口径；所有水位对比仅用相对量（湿面积、CSI、退水方向），绝对水位验证待基准闭合。
4. **海陆边界（v2 已落地，2026-11-23）**：`prepare_jiulong_dem_layers_v2.py` 产出 contract `jiulong_dem_layers_v2`（`data/interim/jiulong/dem_layers_v2/` + `data/catalog/jiulong_dem_layers_v2.json`）——**LAND/SEA/NODATA 三掩膜独立落盘**（sea = S1 常水 ∩ 域边 4 连通，27 格）；负值区 7,838 格（313.52 km²）弃 BFS 平推、改 GLO-30 基准对齐融合（offset −22.766 m，陆域 19,368 格重叠样本），融合体积 −3,011 m³（洪峰蓄量 2.36 亿 m³ 的 1.3e-5，3% 上限内）；7,498 格近岸负值按 GLO-30 证据保留（不钳零，reason=3 显式携带）；海锚 0 为 ADR-0004 模型内部基准约定，随 sea 掩膜显式携带而非隐式钳零。单测 3 项 + v1 契约 43 项全过。
5. **感潮顶托**：TPXO/FES 与风暴增水数据未获 → R4 潮位 = 既有 ztide 合成包络（零相位），定位「情景敏感性」而非「重现观测潮位」，meta 与 verify 双处标注。

## 验收方法

- R 系列 run 的 bci.bci 逐行审计（N=QVAR、S=FREE|HVAR、E/W 无行=闭合）；`run_manifest`/verify.json 记录边界方案；退水期湿面积方向与 S1 同向（validate_jiulong_inundation.py）。

## 不适用条件与回滚

- 水利部门 2024 历史地形/河道档案到位 → 重建 DEM_REPAIRED 与中心线版本，换 run tag；潮位实测/模型数据到位 → HVAR 替换合成潮（新 run）。
