# ADR-0018：概率化与联合阈值探索（集合超越概率 / Copula 联合阈值）

- **状态**：已接受（Accepted）。计划 T12/T13（成功标准 S6）预注册。
- **日期**：2026-11-22
- **触发**：短板 P5（无概率/不确定性框架）。方法来源：钟鸣 Copula 联合阈值（10.1007/s11269-020-02709-y；10.3390/urbansci10090501）+ 小样本信息扩散（10.1007/s11269-019-02266-z）。
- **关联**：ADR-0015（概率产品口径）、ADR-0004（禁业务告警红线）、ADR-0006（湿判据 0.05 m）。

## 决策

### 1. 集合超越概率（T12）

- **成员**：宁明 9 run（3Q×3n 矩阵 `scen_q{2500,4000,6000}_n{35,60,100}_100m`），**强制**以 `mass_recheck_g15.json` 过滤——非 PASS run 禁入集合，成员清单（run、质量门状态、参数档）写入审计 JSON。
- **量**：逐像元 P(wd>thr | 集合) = 成员超阈占比；thr ∈ {0.05（湿判据）, 0.3（情景阈值）}，各成一件 float32 GeoTIFF（0–1）。
- **判据**：event-max（res.max）口径（集合成员各自的模拟全程最大值）。
- **红线**：情景级集合（参数枚举，非贝叶斯后验）；概率图不得解读为年超越概率或预报概率。

### 2. Copula 联合阈值探索（T13）

- **变量**：区域年最大 3 日雨量（ERA5 1979–2025，Open-Meteo archive 采样点均值）× 事件前 30 日雨量 P30（湿度代理，E3——无长序列土壤湿度资料，代理关系登记）。
- **边缘分布**：经验 CDF + 高斯核平滑（实现信息扩散思想，小样本稳健）；不下参数边缘分布。
- **Copula 三族**：Gaussian（正态得分相关）、Clayton（Kendall τ→θ）、t（df 网格 2–10 极大似然）；AIC 选优；纯 numpy 手写（sdv-dev Copulas 许可证 NOASSERTION 未复核，不引入——ADR-0015 §4 依赖策略）。
- **产出**：联合超越概率曲面 P(U>u, V>v) 的参数化结果 + 对照情景矩阵取值；Bootstrap（重采样年样本 100 次）给参数与联合概率置信区间。
- **样本量红线**：n=47 年 → 结果为**探索性**；拟合失败（相关系数/参数越界/AIC 异常）→ 如实记「未验证」，不发布任何阈值。

### 3. 禁止表述（红线）

- **统计阈值仅作情景设计参考，禁止业务告警**（ADR-0004）；
- 联合重现期不得写入交付报告的资产判据；
- 概率产品展示须带「情景集合」与「探索性」双标注。
