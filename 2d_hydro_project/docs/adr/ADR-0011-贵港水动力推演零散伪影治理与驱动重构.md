# ADR-0011：贵港水动力推演零散伪影治理与驱动重构

- **状态**：已接受（Accepted）。本 ADR 由 `plans/贵港水动力推演效果改进实施计划_从零散水点治理到上游来水与降雨双驱动重构.md` 定版。**其中「降雨损失情景」的 Ia/fc 参数标 E3 候选假设，未经本地率定，不得当作已标定值使用**；**Phase 3 河道调理维持阻塞（`BLOCKED_ALTERNATIVE_REQUIRED`），未实施**；**Phase 1 的 ≥90% 斑块去除验收目标未达成，且存在 25.49% 的结构性上界**。
- **日期**：2026-11-02
- **触发**：贵港 2024-09 摩羯情景的推演展示出现 4,422 个离散水点斑块（占斑块数 92.47%，但只占湿体积 3.81%），视觉观感被离散小坑主导；计划把成因归为「浅水坑洼 / 5 cm 地表糙度」并预期用面积+水深滤波去除 80.2%~96.8% 的斑块。Phase 0 实测推翻该定性（离散斑块中位深度 1.03 m，是 DEM 凹坑蓄满的深水），Phase 2+4 实跑进一步否证「施加净雨损失即可消除离散斑块」（loss 情景斑块数反升 36.6%~39.5%）。需要单一 ADR 锁定口径，防止把未达成的验收目标写成达成、把展示滤波当物理修复、把 S1 足迹内指标当模型精度结论。

## 背景

1. **生产情景与唯一变量。** 贵港基线 `scen_yagi_q11500_100m_dt2p5_choff_realdem`：100 m 网格 669×370 = 247,530 像元（`cellsize=100.0`，`cell_area_m2=10,000.0`，从栅格头读取），`q_peak=11,500 m³/s`，`dt=2.5 s`，`channel=off`（`carved_px=0`，无人工刻蚀），`sim_time=1,209,600 s`（14 d），`saveint=21,600 s`（57 帧），`fpfric=0.035`。`E_mass = 6.241e-05` PASS。三个新情景与基线**唯一差异是降雨输入模式**，其余参数逐项相同，因此情景间可比。
2. **基线事实（E1，`res.max`，`depth > 0.05 m`，8 邻域）。** 湿像元 85,256、湿面积 852.56 km²、斑块 4,422、最大斑块 614.96 km²（占湿面积 72.13%）。≤9 格斑块 4,089 个（92.469%），但只占湿面积 11.36%、湿体积 3.81%。**主水体占湿面积 72.13% 却占湿体积 91.95%——面积与体积严重不对等**，这是理解全部后续判断的前提。
3. **降雨账目（E1，两个独立来源交叉验证）。** `V_rain = 247,530 × 10,000 × 135.5 / 1000 = 3.35403150e8 m³`，与 `res.mass` 的 `Rain-(Inf+Evap)` **逐位一致**，确证本 run **零损失**（`run.par` 无 `infiltration`/`evaporation`）。`V_upstream = 5.3784e9 m³`（三角 Q 解析积分，与 `res.mass` 梯形积分相对差 9.5e-7）。雨水只占总入流 **5.87%**，属过境干流主导型洪水。
4. **计划的三处事实性错误。** 见决策项 6，逐条登记更正。
5. **离散斑块的时序归属（E1）。** 斑块暴增帧是 **seq 13→14（t=78→84 h，1,450→7,145，4.93 倍）**，此时上游 Q 仍为基流 1,000 m³/s、累计雨量仅 12.70 mm；斑块数峰值在 seq 16（t=96 h，7,558 个）。**时钟基准：`rain.rain` 时刻列以模型 t=0 = 2024-09-03T00 Asia/Shanghai 为基准（`T0_DAY=3`）。** 实测累计雨量 t=72h→2.60 mm、84h→12.70 mm、96h→27.50 mm、108h→38.60 mm、120h→59.20 mm、144h→74.90 mm、228h→101.30 mm、336h→135.50 mm。若误用 t=0=09-04T00 或 09-05T00，全部累计雨量会整体偏移 24 h 或 48 h。
6. **S1 常水掩膜在本域不可用（E1，定量）。** 09-05 常水掩膜重采样到 100 m 模型网格后：足迹仅覆盖模型域 **26.19%**，北半域（行 0–184）覆盖率 **0.00**；域内常水像元 **1,338 个（13.38 km²）**碎成 **213 个连通块**，最大块 **4.33 km²**（20 m 原栅格）/ **3.38 km²**（100 m 重采样）；而郁江主水体是 **614.96 km² 的单一连通块**，尺寸比 **141:1**。上游 Q 点源在 col0 西边界，注入行带覆盖率 **0.0**。端点退化：**无任何常水块同时触及西、东边界**。
7. **贵港有单景 S1 洪峰观测，但不构成硬门。** 仅 09-12T10:42 一景可用，足迹覆盖 20.6%，固定阈值 −17 dB，风浪/淹没植被偏保守（G17 降级）。CSI/POD/FAR 可算但只能代表足迹内重叠度，不是水深/水位精度指标。

## 决策

### 1. 贵港展示质控层的命名与派生标记

- 贵港展示派生层只允许名称 `display_qc`，路径固定为
  `outputs/display_qc/guigang/2024-09-yagi/scen_yagi_q11500_100m_realdem_display_qc/{A,B,C}/`。
- **禁止**称展示层为「校准」「真实淹没」「物理修复」，禁止暗示其具有物理意义或精度含义。
- 每个派生目录的 `meta.json` 必须包含：`derived_from`、`not_physical_recalculation=true`、`param_hash`、`source_run_sha256`（以 `results/res.mass` 的 sha256 为基准）、`source_res_max_sha256`、`cellsize_m`、`cell_area_m2`、`param_set_id`、`generated_utc`、`caveats`、`alarm`、`rollback`。实测已落盘：`cellsize_m=100.0`、`cell_area_m2=10000.0`（满足平方关系）、`res_mass_copied=false`。
- 派生层目录**不得含 `res.mass`**（会被 `g15_mass_recheck.py` 的 `rglob("results/res.mass")` 计为独立 run，污染质量门计数）。本次实测：`g15_mass_recheck.py` 的 49 个计入 run 中 **`display_qc` 条目数为 0**，派生层判定按 `meta.json` 标记生效，不靠目录名猜测。
- 阈值只用两个口径：**物理面积阈值（km²）** 与 **持续性阈值（连续帧数）**；像元数一律由栅格头换算 `n_cells = ceil(area_km2 * 1e6 / cell_area_m2)`，**禁止写死 4/9 像元或 100 m 单元面积**。
- A/B/C 三档参数**在处理前预注册**并算 `param_hash`；实测三档 `param_hash` 分别为 A `bc396553c1d70fe7bd4f908a97c101cdbb1f86843e7efce3e3ee71129d80cf1e`、B `3900a5078573fa70a1e700aff1879a67007678c73eaa6e3e0ea414a063feedef`、C `b0b2dc6b0e8645bc95895f339c317dfac7d74759d6aa23a252310301b264b030`。**禁止按结果事后挑选或放宽参数。**
- 预注册告警：逐帧湿面积变化率超 5.0% 即 `blocked_for_default_publish=true`。实测三档**全部触发**（A 13.76%、B 23.95%、C 27.48%，均在第 14 帧），故**三档均只能作诊断层，不得默认发布**。该 `blocked` 表示档位不能默认发布，**不表示源 run 有质量问题**。
- 主水体保护改用久隆已验证的「候选主汇流区」定义（按面积降序累计覆盖 50% 湿面积的斑块集合，`main_body_area_fraction=0.5`），**不使用 S1 常水缓冲白名单**（理由见决策项 3）。实测 `largest_patch` 614.96 km² `removed_cells=0`，`kept_area_km2=614.96`，**100% 完整保护**。
- **回滚**：删除派生目录即回退；raw run 逐字节未改动（脚本前后各算一次 sha256，`unchanged=true`，`changed_frames=[]`）。

### 2. 降雨损失情景参数（E3 候选假设，不归因国际规范）

| 情景 | run tag | Ia | fc | 净雨 | 占毛雨 | 有净雨小时 | 穿越时刻 |
|---|---|---|---|---|---|---|---|
| `dualloss_v1` | `..._choff_dualloss_v1` | 30 mm | 2.0 mm/h | **45.40 mm** | 33.51% | 11 h | t=102 h |
| `rainloss_high_v1` | `..._choff_rainloss_high_v1` | 50 mm | 3.0 mm/h | **36.10 mm** | 26.64% | 8 h | t=115 h |

- 毛雨基准 **135.50 mm**（ERA5 市区锚点逐时均匀，123 小时有雨，最大 14.1 mm/h）。
- **参数置信度标 E3 候选假设**：Ia=30/50 mm 与 fc=2.0/3.0 mm/h 是**项目候选参数，未经贵港本地实测率定**。**不归因于 ARR 2019、UK EA 或任何国际规范的强制值**；不得写成「按规范应取」。
- **穿越语义**（冻结口径）：累计毛雨**达到** Ia 的那一小时即穿越（`cum + rain >= Ia`）。`loss_medium` 在 t=102 h 累计 29.5+0.5=30.0 mm 恰好触顶，按此口径得 45.40 mm / 11 h；若改「严格大于」得 47.20 mm / 12 h。`loss_high` 两种语义同值。
- **净雨实现方式**：在生成 `rain.rain` 前对 ERA5 序列施加 Initial Loss / Continuing Loss 变换，**未改求解器**。`rain.rain` 时刻列与基线逐点同源，只改数值，保证可比。
- **`run.par` 不写 `infiltration`**。源码事实：`FPInfiltration`（`infevap.cpp:14-46`）只对 `H > 1e-3 m` 的湿单元扣水，**无法表达初损**；且 fc 已在净雨序列上扣过，再写 `infiltration` 会把 fc **重复扣一次**，破坏「参数即预注册值」的可解释性。计划 §Phase2 把路径 A（净雨预处理）与路径 B（infiltration）并列为两条路径，未意识到两者叠加会重复扣损。该点已写入三个 run 的 `meta.json::rain.infiltration_note` 并附源码依据。
- **交叉核对（E1）**：`res.mass` 的 `Rain-(Inf+Evap)` ÷ 全域面积 2,475,300,000 m² 反算净雨 = 45.4000 / 36.1000 mm，与 meta 登记值**逐位一致**，证明净雨序列被完整无失真送入模型。
- **本构建无法实现「按档位变化的初损参数」**；若要改参数，必须新 run tag、重新预注册，不得覆盖已有 `res.mass` 目录。

### 3. S1 常水路线不可用与 Phase 3 阻塞状态

- **`verdict = BLOCKED_ALTERNATIVE_REQUIRED`，`phase3_implemented = false`，Phase 3 状态 `NOT_IMPLEMENTED（未实施）`。**
- **不可用证据（E1，全部可复核）**：

  | 指标 | 实测 | 判据 |
  |---|---|---|
  | 09-05 足迹占模型域 | **26.14%~26.19%** | 不足以覆盖 614.96 km² 主水体 |
  | 北半域（行 0–184）覆盖率 | **0.00**（5 个十分位全为 0） | 上游无观测 |
  | 域内常水像元 / 面积 | **1,338 个 / 13.38 km²** | 与主水体 614.96 km² 差 141:1 |
  | 常水连通块数（8 邻域） | **213** | 无法提供连续骨架 |
  | 最大常水块 | **4.33 km²**（20 m）/ 3.38 km²（100 m） | 远小于主水体 |
  | ≥100 像元常水块 | **3 个** | 骨架来源不足 |
  | 上游注入行带覆盖率 | **0.0** | 端点退化 |
  | 同时触及西、东边界的常水块 | **无** | 端点退化 |
  | 最长连续河段 | 31 格（3.1 km） | 不构成河道 |

- **这不是执行缺陷**：三次失败尝试的成因已在 `guigang_scenario.py` `prep()` 注释（第 96–105 行）留痕，并经 `scripts/stage6/audit_guigang_channel_route.py` 定量复算。成因是**输入数据固有缺陷**，换实现方式无法修复。
- **替代方案评估（三选，均登记成本/风险/循环论证风险）**：

  | 方案 | 可行性 | 物理依据 | 循环论证风险 | 结论 |
  |---|---|---|---|---|
  | a) 用模型主水体（614.96 km²）反推主槽走廊 | 技术可行，结论可用性低 | **弱**（走廊由模型自身淹没结果决定，非独立观测） | **高** | 不推荐作物理改进；仅可作展示对照且必须标 `derived_from=模型结果` |
  | b) DEM 低带 + Priority-Flood 汇流做骨架 | 技术可行，本域地形无可分辨河谷信号 | 中（纯地形驱动） | 低 | 理论最优但受 DEM 垂直精度限制；D8 三版已失败，**获高精度 DEM 前不应重试** |
  | c) 保持 `channel=off`（现状） | 立即可行 | **强**（不引入任何虚构地形） | 无 | **推荐维持**；已知限制必须显式声明 |

  方案 b 的地形证据：Priority-Flood 抬升 >0 的像元占全域 12.4%；填洼后仍有 **26.1%** 的像元无严格更低邻居（平原带内 40.9%）；平原带为单一连通块 1354.43 km²，内部无分隔性河谷。
- **对 Phase 4 的影响**：三个新情景**全部沿用 `channel=off`，未做任何河道调理**，与基线在河道几何上完全一致，差异只来自降雨损失与上游来水，故情景间可比。
  - **可安全得出的结论**：情景**之间**的差值与相对变化（斑块数、湿面积、S1 CSI/FAR 的相对变化）不受河道几何影响，可用于判断降雨损失假设的方向性。
  - **不可得出的结论**：绝对淹没面积、干流洪峰传播时间、河道内水位绝对值——均受未调理河道影响，**不得作为物理结论或资产判据**。

### 5. 验收目标：达成项与未达成项（逐条如实登记）

#### 5.1 未达成项（必须显式声明）

| # | 计划验收目标 | 计划值 | 实测 | 判定 |
|---|---|---|---|---|
| U1 | 独立斑块总数减少 | ≤450 个（减少 ≥90%，即 89.82%） | A 22.14% / B 22.41% / C 25.49% | **未达成** |
| U2 | 微小斑块占比（≤9 像元） | ≤25% | A 92.71% / B 92.78% / C 92.50% | **未达成** |
| U3 | 物理重构后斑块数 | ≤200 个 | `flow_only_v1` **20**（达成）；`dualloss_v1` **6,041**（+36.6%）；`rainloss_high_v1` **6,167**（+39.5%） | **未达成（loss 情景斑块数反升）** |
| U4 | S1 观测 FAR 压降 | >20% | `flow_only_v1` **11.3%**；`dualloss_v1` **2.2%**；`rainloss_high_v1` **2.4%** | **未达成（三情景全部）** |

**U1/U2 的结构性上界（关键）**：计划 §3 第 2 条把 `max_depth ≥ 0.50 m` 的斑块**全部豁免**，该规则下可去除斑块理论上界仅 **1,127 个 = 25.49%**。C 档实测 25.4862% **已达该上界**（占上界 99.5%）。**≥90% 目标与计划 §3 的规则结构直接矛盾**，不是实现不足。要突破该上界只能**修改规则结构**（例如把深水豁免从「绝对」改为「按档位」），且任何规则变更都必须作为**新预注册参数集**登记，不得回填到 A/B/C。

**计划预测值的来源（必须说明）**：计划 §4 的「预期去除斑块比例」= **纯面积谱累计占比**（A 80.19% vs 计划 80.2%、B 92.469% vs 92.5%，前两档逐位吻合；C 97.671% vs 96.8%，差 0.87 pp 但在 1 pp 内），**未计入计划自己写的深水豁免规则**。因此该预测值不能作为验收基线。

**U3 的否证性机制（E1，已验证）**：三个降雨情景的湿像元**全部是基线的真子集**（`only_self=0`），**无新增水**。斑块数上升来自**主水体被切碎**：主水体 614.96 → 543.97 km²（−70.99 km²）；基线主水体 61,496 像元中 3,270 像元（5.3%）仍湿但被切到外围小斑块；外围斑块水深中位数 0.344 → 0.222 / 0.211 m；单像元斑块 1,922 → 3,210；≥1 km² 大斑块 14 → 7。机制是**净雨削减使浅滩水深跌破 0.05 m 判据，把连片滩地切成孤岛**（典型「大切小」）。**因此「减少水量」与「减少斑块数」在本域是两个相反方向的目标，斑块数不是衡量本治理目标的好指标。**

**U4 的解读**：`flow_only_v1` 的 CSI 从 0.076 升到 0.164（+0.088），但这是**模拟水体向观测水体收缩**造成的重叠度改善，**湿面积同时下降 −37.9%**（852.56 → 529.52 km²）。CSI 上升不证明预测更正确，须与面积一并读。

| M5 | S1 观测 CSI 有效提升 | 「有效提升」（计划未给数值门槛） | `flow_only_v1` +0.088、`dualloss_v1` +0.017、`rainloss_high_v1` +0.019 | **达成（按本项目自定的 `delta_csi > 0` 判定；该阈值非计划原文）** |

**M5 的口径保留**：计划未定义「有效提升」的数值门槛。本 ADR 采用 `delta_csi > 0`，该阈值属**本项目自定**，不得表述为计划原文要求。且「CSI 提升」与「FAR 压降 >20%」**不是同一件事**：三情景 FAR 压降 2.2%~11.3%，**均未达 >20%**。

### 5.3 派生 `res.max` 的双口径（发布前实测修正，必须遵守）

派生层 `res.max` 的生成方式在发布校验阶段做过一次**实测驱动的修正**，原因是它一度导致 `floodviz validate --full` 判 **4 项失败**（「res.max 存在小于逐帧采样值的像元（违反单向性）」）。修正与口径如下。

**问题**：逐帧按**轨迹/像元**判定，`res.max` 按**斑块**判定，两套粒度不同。一个像元可能在 `res.max` 里所属斑块被判 filter（被清零），却在某一帧里所属斑块判 keep（该帧保留），于是派生 `res.max` 低于派生逐帧，破坏 `res.max ≥ 逐帧` 的单向性断言（`pipeline.py`）。实测 A 档有 1,732 像元违反，最大差 0.0500 m。

**修正**：派生 `res.max` 一律取**全部保留帧的逐像元最大水深（包络）**，单调性由构造保证；再对主水体像元取源 `res.max` 原值以守住 §4 的 614.96 km² 完整保护。此路已验证：三档违反单向性像元数均为 **0**。

**由此产生的双口径（禁止混用）**：

| 口径 | 字段 | 含义 |
|---|---|---|
| A（斑块判定口径） | `verdict_removed_cells` / `patch_removal_pct` | 源 `res.max` 的**斑块级判定**删除量，**对齐计划 §4 的 4,422 斑块口径**。U1 的 22.14/22.41/25.49% 出自此口径 |
| B（包络实际口径） | `removed_cells` / `kept_wet_cells` / `area_change_pct` / `volume_change_pct` | **派生包络**相对源 `res.max` 的实际变化。源 `res.max` 是子步累积包络、含帧间峰，派生包络只由 6 h 采样帧构成，故 B 的减少量必然大于 A |

实测两口径并列（A 档）：`verdict_removed_cells` 1,778 → 面积 −2.09%；`removed_cells` 4,620 → 面积 **−5.42%**、体积 −0.2633%。**报告时必须标注口径**，`area_change_pct` 不得与 `patch_removal_pct` 混用于同一句结论。

**同类修正（原始模型输出侧）**：`flow_only_v1` 的源 `res.max` 有 **9 个像元**被 6 h 采样帧超出，差值**恰为 0.0010 m**。这是 `.wd` 输出量化步长（`output.cpp:686` 以 `%.3f` 写盘）导致的精度伪影，不是物理不一致。据此把 `pipeline.py` 的单向性容差从 `-1e-9` 改为**一个量化步长 0.001 m**，超过一步仍判失败，断言强度不变。该修正对久隆/宁明无影响（两者差值均 ≤0）。

### 6. 计划文档三处错误的更正登记

| # | 计划原文 | 实测 | 更正 |
|---|---|---|---|
| **C1** | §1.2 称离散斑块是「浅水坑洼」「5 cm 仅是地表糙度」 | ≤9 格斑块 `max_depth` 中位 **1.034 m**、p90 **2.335 m**、最大 **12.06 m**；只有 996 个（24.4%）低于 0.30 m | 改为「**DEM 凹坑蓄满形成的深水小坑**（中位 1.03 m），非浅水膜」。全域 74.65% 湿面积水深 >0.50 m。**这直接决定任何基于水深阈值的过滤对它们基本无效** |
| **C2** | §3 Phase 0 任务 3 写上游注入「≈ 5.5×10⁸ m³」 | **5.3784e9 m³** | **差一个数量级**，应为 5.5e9 量级。与 `res.mass` 梯形积分相对差 9.5e-7 |

**三处错误的共同性质（必须说明）**：C1/C2/C3 全部是**计划撰写阶段的事实性偏差**，不是执行阶段的偏离。本项目在 Phase 0 诊断中逐项复算并登记，**未据此修改任何计划参数、阈值或情景设置**。三处更正只影响文档表述与验收基线的选取，不影响任何 run 的数值结果。

### 8. 站点水位诊断（G7 降级口径，仅诊断不作闸门）

- 贵港站 09-12T14 洪峰水位 **43.09 m**；模型锚点「贵港市区郁江段」（109.60, 23.11）7×7 窗口内湿格最大 WSE **28.30 m**，apparent offset **14.79 m**。09-14T05 时点：站点 44.00 m / 模型 28.15 m / offset 15.85 m。
- **G7 垂直基准未闭合**：站点水位为站基面，模型 WSE 为 DEM 高程基准，**二者差值不是 `datum_offset_m`**。
- **两个时点的 apparent offset 彼此不一致（14.79 vs 15.85）**，故**不得用作率定值、不得用作同峰对齐依据**。
- 本项**仅诊断，不作闸门，未参与任何验收判定**。模型 WSE 取邻域 7×7 包络最大值，不是站点单点水位。
- 四情景的该诊断值一致（28.30 m / 14.79 m），因为锚点邻域在本时刻已由干流过境主导，降雨差异不影响该处 WSE。

- **禁止表述清单**（本次重申并扩充）：
  - 不写「ARR 2019 规定/强制」等未核验的规范归属。
  - 不把展示层称为「校准」「真实淹没」「物理修复」。
  - 不写「红壤地区初期必然吸收 30–50 mm」。Ia/fc 只能作为 E3 待试验假设。

## 后果

### 正面后果

- **根因一得到强支持**：关闭降雨使斑块数从 4,422 降到 **20（−99.5%）**，外围小斑块面积 237.60 → **0.29 km²（−99.9%）**，单像元孤岛 1,922 → **14**。**离散水点确由无损失降雨造成**，计划根因一成立。
- **否证性结果被完整保留**：loss 情景斑块数反升（+36.6% / +39.5%）如实登记，未调阈值凑数。这直接推翻了「施加净雨损失即可消除离散斑块」的预期，并把「斑块数不是本治理目标的好指标」写入 ADR，防止后续按错误指标继续调参。
- **展示层可回滚、可追溯、可复现**：派生标记齐全，raw 哈希不变，参数哈希可复核，raw 与 `display_qc` 可一键切换。
- **Phase 3 阻塞有定量证据支撑**：不再是「实现失败」，而是「输入数据固有缺陷」，避免后续重复尝试同一失败路线。
- **质量门口径唯一**：49 run 计数可复核，`display_qc` 零污染，消除「全量通过」这类不可复核表述。

### 负面后果与限制

- **Phase 1 的 ≥90% 去除率未达成，且存在 25.49% 的结构性上界。** 这是计划 §3 规则结构与数据事实（离散斑块是深水）的冲突，不是实现缺陷。**任何声称已达成 ≥90% 的表述都是错误的。**
- **三个 `display_qc` 档位全部 `blocked_for_default_publish=true`**（逐帧面积变化率 13.76% / 23.95% / 27.48% 均超 5.0% 预注册上限，发生在第 14 帧涨水段）。三档只能作诊断层，**不得默认发布**。根因是最差帧 seq 14（t=84 h 涨水段）湿面积仅 243.89 km² 而峰值帧 769.97 km²，离散斑块占比高。
- **`display_qc` 不改变物理结果。** 它带 `not_physical_recalculation=true`，只能作为展示层；不得用于任何物理结论、验证指标或资产级判据。
- **「干流传导受阻」限制未被消除。** 三个新情景全部 `channel=off`，上游 11,500 m³/s 三角来水在无河槽的宽平底平原上扩散，干流输运能力可能被低估。**任何基于绝对淹没面积的结论都必须带此限制声明。**
- **Phase 3 河道调理维持阻塞。** 三条替代路线均有明显缺陷（a 循环论证风险高、b 受 DEM 垂直精度限制且已失败三次、c 接受限制）。解除阻塞需要独立河道资料（实测断面、航道图或高精度 DEM），当前不可得。
- **贵港独立验证仍不足以构成硬门。** 仅单景 S1（足迹 20.6%、固定阈值 −17 dB、G17 降级）；**NSE、R²、水深误差未测**；水位诊断受 G7 阻塞。CSI/POD/FAR 只代表足迹内重叠度。
- **`flow_only_v1` 的 CSI 提升伴随湿面积 −37.9%。** 两者必须一并读；单看 CSI 会得出「模型变准了」的错误结论。
- **降雨损失参数未经本地率定（E3）。** Ia/fc 取值为项目候选假设，换一组参数会得到不同的净雨与斑块数。**不得把本次三档结果当作贵港下渗特性的结论。**

## 替代方案

| 方案 | 内容 | 不采纳理由 |
|---|---|---|
| 调整 A/B/C 阈值以凑到 ≥90% 去除率 | 放宽面积/水深上限直到斑块数 ≤450 | 违反预注册纪律；且深水豁免构成 25.49% 硬上界，**调阈值根本无法突破**，只能改规则结构 |
| 把深水豁免从「绝对」改为「按档位」 | 让三档的水深豁免阈值随档位变化 | 属**规则结构变更**，须作为新预注册参数集登记、需用户批准；且会删掉大量中位深度 1.03 m 的深水斑块，与「不误删真实积水」冲突。保留为后续候选 |
| 用 S1 常水掩膜做河道骨架与主槽白名单 | 按计划 §Phase3 原设计实施 | 定量证据表明掩膜在本域不可用（足印 26%、北半域 0、213 块、最大 4.33 km²、端点退化），见决策项 3 |
| 用模型主水体反推主槽走廊并刻蚀 | 解决干流传导受阻 | 循环论证风险高：用结果定义地形再用地形复现结果，验证指标会被人为改善，无法与「物理正确」区分 |
| 只做视觉平滑，不做斑块统计 | 用渲染手段消除噪点 | 不可审计、不可复现、不可回滚；无法区分「删掉噪点」与「删掉真实积水」 |
| 把 `display_qc` 设为默认展示层 | 直接用三档替代 raw | 三档 `blocked_for_default_publish=true`（逐帧面积变化超 5% 预注册上限）；且默认层切换需用户确认，用户本次未表态 |
