# ADR-0012：贵港水力约束河槽重构（水力几何先验 + 参数化刻蚀）

- **状态**：已接受（Accepted）。依据 `plans/无实测水下地形条件下的河槽水力刻蚀与几何重构算法（针对贵港干流漫滩）.txt` 技术调研，用户 2026-11-07 批准执行并批准首轮 5 个深度情景重跑 lisflood.exe。
- **日期**：2026-11-07
- **触发**：贵港基线（`channel=off`）S1 洪峰景 FAR 0.817~0.921（`guigang_s1_validation.json`），根因之一为「干流传导受阻」（ADR-0011 决策 3）。调研提出不依赖 S1 骨架与 DEM 山谷的水力约束重构路线；本 ADR 锁定其口径，防止把情景假设写成实测地形、把重叠度指标写成精度结论。

## 背景

1. **ADR-0011 决策 3 的阻塞范围不变。** S1 常水掩膜骨架（213 块、端点退化）与 DEM 山谷追踪（平原无河谷信号，D8 三版失败）两条路线的失败结论维持有效。本 ADR **不是**对它们的重试。
2. **新路线的输入来源（循环论证风险规避）。** 中心线来自 OSM Overpass 外部水系矢量（用户 2026-11-07 决策；回退链：Sentinel-2 2024-10-03 低水景水面骨架 → 参数化直线，全部在审计 JSON 登记）；几何参数来自公开工程先验 + Manning 反演（预注册 `guigang_channel_priors.json`）。**两者均不来自模型淹没结果**，与 ADR-0011 否决的「替代方案 a（模型主水体反推走廊）」划清界限。
3. **高程口径。** 深度为**相对岸顶**口径（岸顶 = 沿线 DEM 平滑面），规避 G7 垂直基准未闭合（城区平原 DEM 约 21 m vs 贵港站洪峰 43.09 m）。不引入绝对水位高程。
4. **求解器事实。** 本构建支持 `manningfile`（pars.cpp:234；input.cpp:909-940，nodata 格回退 `fpfric`），主槽/滩地差异化糙率可直接落地；无亚网格河道（模型横幅 Rectangular channels only），100 m 网格主槽仅 2~3 格宽，以 4×4 亚采样聚合缓解。

## 决策

### 1. 三层 DEM 契约（沿用久隆 dem_layers 命名）

| 层 | 内容 | 本轮状态 |
|---|---|---|
| `dem_raw` | 源 DEM（`data/interim/guigang/dem_12p5m_32649.tif` 及其 100 m 走廊网格） | 原样，哈希登记 |
| `dem_hydro` | 水文调理层 | **v1 零修改**（登记理由：LISFLOOD-FP 为二维求解器，.txt 的 `DEM_flow`/D8 预处理不适用；真实洼地按 ADR-0011 保留） |
| `dem_hydraulic` | 水力重构层 | 圆滑梯形刻蚀（smoothstep 岸坡、4×4 亚采样、`Z_new=min(Z_orig, Z_ideal)`、走廊外零修改、床面顺流单调） |

### 2. 预注册与情景矩阵

- 刻蚀参数在生成任何重构 DEM 与跑任何 run 之前冻结于 `data/catalog/guigang_channel_priors.json`（matrix_id `guigang-channel-priors-v1`）；构建脚本复算主槽分流比 α 并与冻结值核对，超差即拒绝执行。
- 首轮矩阵：深度 A~E = 10/12/14/16/19 m（α = 0.3835/0.5063/0.6375/0.7754/0.9913，E 档接近主槽独立承载的解析上限 19.12 m）；`W=300 m`、`S=0.000116`（仅用于反演与核验，不进模型）、`n_main=0.030`（manningfile 主槽掩膜覆写）、边坡 2H:1V、`B=W−2zD`。
- **滩地糙率首轮维持基线 `fpfric=0.035`**（用户决策：单变量控制，FAR 变化可归因于河槽几何）；滩地糙率敏感性留第 2 轮。

### 3. 运行与验证

- 5 个新 run：`scen_yagi_q11500_100m_chhyd_d{10,12,14,16,19}`，其余参数与基线逐项相同（`q_peak=11500`、`dt=2.5`、`sim_time=14 d`、`saveint=21600`）；全部经 `guard_no_overwrite`。
- 三层验证：①几何 6 项（中心线连续、河宽对先验 250~320 m、纵坡无逆坡突变、断面无尖坎、岸坡衔接、无孤立深坑）；②输水核验（重构 DEM 实测断面反算 Q(D)/Q_p 对冻结 α，|误差| ≤ 5%）；③S1 09-12 洪峰景 POD/FAR/CSI（口径不变：t=228 h、足迹内、wet>0.05，`area_sim_in_footprint_km2`）。
- 质量门：5 个新 run 计入 `g15_mass_recheck.py` 全表刷新；`PASS` 只证明水量账目闭合。

### 4. 禁止表述清单

- 不得称重构 DEM 为「实测水下地形 / bathymetry / 真实河床」；只允许「水力一致性河槽先验地形（情景假设）」。
- 不得称 α（主槽分流比）为观测值或率定值；19 m 深槽是主槽独立承载的极限情景，不是设计断面。
- 不得把 CSI/POD/FAR 的改善写成模型精度提升；FAR 压降只说明足迹内重叠度变化。
- 不得在未做第 2 轮糙率实验前声称「几何与糙率已校准」。
- 不得删除或改写 `channel=off` 基线的地位；本路线是**新增候选情景层**，基线仍是 channel=off。

## 后果

- **正面**：主槽输水通道建立后，「干流传导受阻」限制有了情景级对照；首轮矩阵可定量回答「河槽深度对 FAR/湿面积的影响方向与量级」。
- **负面/限制**：100 m 分辨率对 300 m 河宽勉强显式（2~3 格），19 m 深槽岸坡过渡不足 1 格；OSM 中心线精度未独立核验（以锚点距离 + 河宽核验代理）；α 为情景假设。
- **中性**：30 m 网格对照（约 12 h/run）列为后续可选项；第 2 轮滩地糙率矩阵（0.045~0.080）待首轮结论。
