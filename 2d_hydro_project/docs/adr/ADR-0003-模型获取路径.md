# ADR-0003：主模型 LISFLOOD-FP 获取路径

- **状态**：已由 ADR-0007 接续（LISFLOOD-FP 8.1 已构建并使用；许可仍待核验，不再等待“是否获取”决策）
- **日期**：2026-10-24

## 背景

终稿 5.1/0.3：主模型候选为 LISFLOOD-FP CPU 求解器，须确认版本、构建方式、许可后跑官方案例与项目基准。阶段 0 探测（data_reachability.md）：官网 https://www.seamlesswave.com **可达**（直连/代理均 200），获取障碍仅为**注册下载需真实身份信息**，代理不代为注册。

## 选项

1. **（推荐）用户在 seamlesswave 官网注册并下载 LISFLOOD-FP 最新稳定版（8.x）**
   - 注册需姓名/单位/邮箱；下载后放入 `data/raw/`（不入库），登记版本与许可到 model_manifest.yaml。
   - 随后启动阶段 2：Windows 构建或 WSL 编译验证 + 官方最小案例。
2. 用户提供已有安装包/镜像（内部分发渠道）——同 1，须附版本与来源记录。
3. 若获取受阻超过阶段 0 排期：先评估 HEC-RAS 2D（入口可达，仅代理），但须按终稿 5.1 重新走选型流程并出独立 ADR。

## 后续动作（任一选项生效后）

- 填写 `configs/model_manifest.yaml` 的 version/build/license 字段；
- 按终稿 十一章 7 项基准 + 性能实测（内存 16GB、磁盘预算为硬约束）出基准报告；
- 形成 ADR-0004 锁定模型版本。

## 风险

- 延迟获取将顺延阶段 2/3 全部排期（终稿 十二）。
