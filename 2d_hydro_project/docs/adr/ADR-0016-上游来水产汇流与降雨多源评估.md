# ADR-0016：上游来水产汇流与降雨多源评估（GR4J / MMF / 复合矩阵预注册）

- **状态**：已接受（Accepted）。计划即授权（§5.3 五个 run）；本 ADR 在 A1 边界生成前预注册。
- **日期**：2026-11-22
- **触发**：短板 P1（上游来水无产汇流物理）与 P2（降雨驱动单一）。方法来源：吴欢 DRIVE（10.1002/2013WR014710）、S2S-IHC（10.1175/JHM-D-25-0015.1）、MMF（10.1175/JHM-D-15-0149.1 / JHM-D-20-0213.1）；钟鸣复合洪水（10.1016/j.jhydrol.2023.130475）。
- **关联**：ADR-0015（产品口径）、`data/catalog/guigang_inflow_priors.json`（面积与参数预注册）。

## 背景

1. 贵港郁江入流为手工三角过程线（`yujiang.bdy` 10→115→20，file_value=Q/cellsize）；宁明为 Q 档位情景；均无产汇流物理。
2. 无实测流量序列 → 不做率定（计划 §6.5）；GloFAS 只作先验对照、不作拟合目标（防循环论证）。
3. 公开来源核验（2026-11-22）：郁江贵港以上控制面积 87,780 km²（径流深反推，±5%）；明江全流域 6,379 km²（宁明以上上限口径）。**面积值待用户复核**（priors JSON `pending_user_review`）。
4. LISFLOOD-FP 8.1 边界语义（源码实证）：bdy 第二行 = `<点数> <时间单位>`（`input.cpp::LoadTimeSeries`），数据行 `<值> <时间>` 且时间严格递增；QVAR 值 × dx = 流量（`sgc.cpp` Q_multiplier=dx）；HVAR 值 = 水面高程 m（`boundary.cpp` `hflow=max(H, h0−DEM)`）。

## 决策

### 1. GR4J 型集总产汇流（A1，服务 S3）

- **结构**：标准 GR4J 日模型（Perrin et al. 2003, J. Hydrol. 279），无雪模块，纯 numpy 手写（约 200 行）。公式取参考实现（hydromad `gr4j.R`，与 airGR 同源）逐条核对：
  - 生产库：`Ps = X1(1−Sr²)tanh(Pn/X1)/(1+Sr·tanh(Pn/X1))`，`Es = S(2−Sr)tanh(En/X1)/(1+(1−Sr)tanh(En/X1))`；
  - 渗漏：`Perc = S(1−(1+(4/9·S/X1)⁴)^(-1/4))`（参考实现口径）；
  - 单位线：`SH1(t)=(t/X4)^2.5`（≥X4 取 1）；`SH2(t)=0.5(t/X4)^2.5`（t≤X4）、`1−0.5(2−t/X4)^2.5`（X4<t≤2X4）、1（t>2X4）；
  - 90% 经 UH1 入汇流库，10% 经 UH2 直排；汇流库 `Qr=R(1−(1+(R/X3)⁴)^(-1/4))`；交换项 F=X2(R/X3)^3.5。
- **参数**（预注册 priors JSON，文献通用区间中值）：X1=350 mm，X2=0（无交换——情景级不引入无资料约束的交换项；F=0 时 F/2 vs F 的实现分歧无影响），X3=90 mm，X4=1.7 d。
- **敏感性**：X1∈{175,350,700}、X3∈{45,90,180}、X4∈{1.0,1.7,3.0}，单变量三档（OAT）；不做自动率定。
- **IHC（吴欢 S2S 教训）**：主口径 = 35 天真实雨/ET 暖启动结束状态；对照口径 = GA 预处理器网格均值映射 S_init/X1=θ_mean/θ_s；两口径差异登记进 `inflow_audit.json`。
- **输入**：Open-Meteo archive API（ERA5）日降水与 ET0（`et0_fao_evapotranspiration`），流域 bbox 采样点算术平均（郁江 0.5° 间距、明江 0.25° 间距，清单随审计登记）。
- **日→时**：逐时等分，日水量守恒（余量入当日最后一小时）。
- **bdy**：格式与既有完全一致（名称行 + `<count> seconds` + `<Q/cellsize> <t>`，t 严格递增）；GR4J 边界只写**新建** run 目录，`guard_no_overwrite` 前置。
- **验证（S3）**：与 GloFAS 日流量先验对照（通道：cdsapi 有 key 时用 GloFAS-ERA5 再分析；否则 Open-Meteo flood API（GloFAS v4）无凭证抽样），Pearson r ≥ 0.7 达标；未达记「未验证」；量级差如实登记（2024-09 贵港格点峰值 23,550 m³/s vs 实测 10,500——先验偏大 ~2.2 倍已登记 priors）。

### 2. MMF 降雨多源评估（A2，服务 S4）

- 协议：同一模型、同一 GA 净雨链、同一验证景，仅替换降雨驱动；评「洪水响应差异」而非雨量本身。
- IMERG V07 30 min 0.1°：反累计解析 + 时基归一到事件窗（UTC+8 对齐 ERA5 探针链），再经同一 `net_rain`/GA 链生成净雨 `.rain`。
- 数据前提：Earthdata 凭证；不可得则记「数据不可得」，S4 记「未验证」（计划 §6.4），脚本与合成单测仍落地。
- 报告三段：面雨量偏差 → 湿面积/CSI 传播比 → S1 POD/FAR/CSI 差异表（同 `guigang_s1_validation.json` 口径）。

### 3. 复合洪水情景矩阵与授权 run（§5.3 清单）

| run | 上游 | 下游 | 降雨 | 质量门预期 |
|---|---|---|---|---|
| `scen_gr4j_q_100m` | GR4J Q(t) | FREE | ERA5 净雨（同锚点） | PASS |
| `scen_zdown_a_100m` | 既有锚点三角 Q | HVAR Z_a | 同锚点 | FAIL-EXPLAINED 预注册（HVAR 边界通量口径，G13 先例） |
| `scen_zdown_b_100m` | 既有锚点三角 Q | HVAR Z_b（低档） | 同锚点 | 同上 |
| `scen_imerg_ga_100m` | 既有锚点三角 Q | FREE | IMERG 净雨 | PASS |
| `scen_gr4j_q6000_100m`（宁明） | GR4J Q(t) | FREE | ERA5 净雨（同锚点） | PASS |

- **Z(t) 情景 a/b 定值规则（预注册）**：`bed_ref = E 边界列 dem.asc 非空值第 10 百分位`；`Z_a = bed_ref + 4.0 m`（强顶托档）、`Z_b = bed_ref + 1.0 m`（弱顶托档）；常数序列（首尾两点）。实际数值在组装时算出并写入 run 的 `meta.json` 与审计。
- **run 组装纪律**：新 run 目录复制锚点 run 的 `dem.asc`/`bci.bci`/`manning.map`/`rain.rain`（字节级复用，provenance 记源哈希），仅替换边界件与 `run.par` 的 `bdyfile`/`bcifile`；`run_manifest` 记 config_snapshot 含源 run 与替换件哈希。zdown 系列另改 E 边线 `FREE → HVAR zdown_a/b`。
- **禁止**：清单外 run 一律单独批准；任何 run 落 FAIL 即停线排查。

### 4. 验证与登记

- 新 run S1 验证沿用 `guigang_scenario.py::verify()` 指标定义与足迹口径，回填 `guigang_s1_validation.json`（追加不重写）。
- 面积未复核前，交付文本不得出现「率定」「预测」「断面面积已确认」表述（priors JSON `prohibited` 清单）。

## 后果

- **正面**：上游边界首次具备产汇流物理与守恒审计；GloFAS 先验对照使 S3 可测；贵港获得外洪顶托（Z_a/Z_b）与降雨多源（R1）差分角点。
- **限制**：GR4J 为 E3 情景级（参数文献中值、无率定）；面积推算待复核；MMF 依赖 Earthdata 凭证；HVAR run 质量门预期 FAIL-EXPLAINED（不计通过）。
