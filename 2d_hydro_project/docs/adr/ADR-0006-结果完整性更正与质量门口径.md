# ADR-0006：结果完整性更正与质量门口径

- **状态**：已接受（Accepted）
- **日期**：2026-10-26
- **触发**：终审发现贵港 WSE 干像元伪值、久隆站址远邻域伪值、宁明 `res.max` 时刻错配、质量门 N/A 绕过、产品伪到达。

## 决策

1. **WSE 只在湿像元上计算**：`wd>0.05` 才计入 `dem+wd`；干帧记 `null`。贵港旧 7×7 窗口 `max(dem+wd)` 的 30.01 m 与 +13.08 m 基准率定作废。q11500 事件峰 25.06 m；09-12T14 湿像元 21.92 m vs 43.09（apparent offset +21.17），09-14T05 20.00 vs 44.00（+24.00）。offset 非常数，G7 未确认前不得写入 `datum_offset_m`。
2. **站址主口径 ±2 格（面积级）**，另报像元中心值；不得用 ±5 格/远邻域最大值冒充站址。久隆像元 0.008 m、±2 格 0.547 m、±5 格 1.684 m（1.28 km）；宁明像元 0.018 m、±2 格 10.32 m。
3. **SAR 验证按影像时刻切片**：宁明主帧 78h（8/24 08:00 中心，±6h）；不再用 `res.max` 做验证。主阈值 0.15 m 预注册，0.05/0.30 只作敏感性；不得按 CSI 选阈值。
4. **质量门三分**：PASS（≤1e-3）、FAIL-EXPLAINED（HFIX/HVAR + G13，明示原因，不计通过）、FAIL。禁止 N/A-HFIX。B2 基准质量增益 +0.82% 记 FAIL；B6/B7 仅诊断；B8 未跑。
5. **产品口径**：到达=首个 `wd>0.05` 快照；峰值时刻=`res.maxtm`；历时=`res.totaltm`；面积分“全历时包络/峰时单帧”；站址分 cell/±2。
6. **追溯**：新增 `code_manifest.json` 与 `run_manifest.py`；代码未入 git 前以树哈希留痕；input_manifest 覆盖贵港 DEM、S1/GF-3、配置。

## 后果

- 首版报告/摘要中的 30.01、+13.08、1.68 m 站址、11.88 m 站址、CSI 0.387、108 点、B1–B7 全部通过均标记作废。
- 贵港 WSE 仅诊断；宁明面积仍约 1.9–2.0× 偏大；久隆站址像元基本不积水。全部结论仍为情景级。
- 空间 Manning（G18 修正）、网格/时间步敏感性、结构定量、喀斯特标量入渗仍在 Phase B。
