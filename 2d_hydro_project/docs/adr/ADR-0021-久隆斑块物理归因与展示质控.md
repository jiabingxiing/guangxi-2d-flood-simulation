# ADR-0021：久隆水淹斑块物理归因（P01–P08）与展示质量控制

- **状态**：已接受（Accepted）；首版归因已落盘（2026-11-22）。
- **日期**：2026-11-22
- **触发**：旧 4/9 像元规则在峰值帧曾误删 764 斑块（53.92 km²），其中 205 个 >90% 帧持续；贵港 R2 绝对深度豁免锁死去斑天花板 25.49%（ADR-0011）。一刀切滤波弃用，改为逐斑块物理成因归因。
- **关联**：ADR-0010（四层 DEM 契约）、ADR-0011（贵港 display_qc 经验）、ADR-0019/0020。

## 决策

1. **八类成因 P01–P08 优先级判定**（预注册，`scripts/stage6/diagnose_jiulong_patch_attribution.py` 模块 docstring 与 class_summary.json 双回显）：
   P05 海面钳零（class==1 占比 ≥0.5）→ P02 地形改写（class∈{2,3,5} ≥0.5）→ P07 边界异常（触网格边缘）→ P06 数值薄水（中位深 <0.10 m 且持续性 <3 帧）→ P03 河网断裂（距河 ≤1 km 且 HAND ≤3 m 且非主体）→ P01 自然洼地（中位深 ≥0.10 m、无改写、HAND ≤5 m、汇流 ≥100 格）→ P04 局地降雨积水 → P08 排水受阻（残差默认）。
2. **15 项指标**：面积（栅格头 cellsize，禁硬编码）、最大/平均/中位水深、体积、持续性帧数、连续时长、首末时刻、距河距离（OSM 干流 BFS）、距排水距离（汇流 ≥50 km² BFS）、HAND（Priority-Flood+ε + D8，eps=1e-5，平点梯度指向溢出口）、汇流累积、地形改写重合率、边界距离、轨迹匹配 id、置信度（命中规则数 3/2/1 → high/medium/low）。
3. **处置口径**：P06 = filter_eligible（唯一允许审计规则处理）；P02 = repair_first（须在 DEM_REPAIRED 层修复后物理重算）；其余六类 verdict=preserve，**禁止展示层直接删除**；长期持续真实斑块保留独立 `ISOLATED_DEM_PIT` 类审计口径（对接 display_qc 修订）。
4. **首版实测（E1，基于冻结诊断快照 + scen_free_200m_sv6h）**：1,107 斑块全分类——P01=60、P02=123、P03=2、P04=882、P05=0（海钳零格水深恒 0，仅合成用例可命中）、P06=10、P07=12、P08=18；轨迹空间匹配 1,085/1,107（未匹配诚实记 -1/单帧）。
5. **demo_qc 修订方向**（打破 25.49% 天花板，与贵港同步推进）：R2「水力连通性 + 洼地深度比（pit_depth/max_depth ≥0.80）」双门控替代绝对深度豁免；深坑并入 `ISOLATED_DEM_PIT` 审计层而非主洪水面；验收改「非连通孤立面积占比 + 主水体体积保真率 >99.5% + 绝对面积/相对比例双阈值帧门禁」。

## 验收方法

- 100% 湿斑块入表（1,107/1,107）；`patch_class_map.tif` 湿像元覆盖与 res.max 一致；单测 20 项合成用例 PASS；派生层零 `res.mass`（不进 g15）。

## 不适用条件与回滚

- 新基线 run（R 系列）产出后须重跑归因（新 run tag）；P01–P08 门限修订须先改预注册表并重新出图，禁止事后逐斑块手工改类。
