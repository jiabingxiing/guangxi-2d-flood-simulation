# ADR-0005：范围调整——变电站按整体处理，设备级推演推迟

- **状态**：已接受（Accepted）
- **日期**：2026-10-24
- **触发**：用户答复——不关注设备级/房间级水位推演；将变电站视作整体，推演其所在区域的洪涝情况即可。

## 决策

1. 模拟对象为**变电站所在区域的洪涝场**（淹没范围、水深、到达时间、历时），变电站作为整体资产暴露其中；不做变电站内部设备/房间级推演（留待未来任务）。
2. 站区局部精细模型（1–5 m）**整体推迟**：其先决条件（地坪/围墙/站门/涵洞测量）不再列为当前必需项；缺口 G1 相应降级。
3. 站区在模型中的表达（背景网格尺度）：以 DEM 可辨范围 + 影像筛查近似（围墙/建筑作地形障碍或高糙率处理），**该近似的误差须在产品中明示**；不虚构未测量的门/涵洞细节。
4. 风险产品输出：站区范围内最大水深/淹没历时统计 + 与资产台账的关联字段（台账到位前仅输出空间统计）。

## 影响

- 数据需求下降：竣工图/站区测量从「阻塞」降为「可选增强」。
- 网格策略简化：三案例均以区域背景网格为主（久隆 12.5 m、宁明 25 m、贵港 30 m），不再规划 5 m 局部网格。
- 站区安全门禁（终稿 13.4）相应降级为「区域水深参考 + 业务部门复核」，不再依赖设备防水等级数据。
