# ADR-0004：公开数据降级模式与垂直基准策略

- **状态**：已接受（Accepted，条件见后）
- **日期**：2026-10-24
- **触发**：用户答复——无水文/气象/业务部门授权数据；以网络公开数据 + 本地已有数据推进；实在缺失的按模型粗略降级。

## 决策

### 1. 数据基线（降级模式）

| 数据类 | 降级基线 | 保留的正式途径 |
|---|---|---|
| 地形 | 本地 `广西.tif`（12.5 m，32648；来源/垂直基准待查证）为主基底；FABDEM/GLO-30 仅交叉校验 | 查证来源后可替换；测量级 DEM 到位后升级 |
| 降雨 | Open-Meteo ERA5/ERA5-Land（逐时，≤8 天分段请求）为主驱动；IMERG 交叉校验 | 雨量站/雷达 QPE 到位后升级 |
| 河道边界 | 无逐时 Q(t)/Z(t) → **河道型事件（宁明/贵港）降为情景级/条件性结论**；河槽用 DEM + MERIT Hydro 先验做有界情景 | 授权记录到位后升级 |
| 潮位（久隆） | 公开潮汐模型算天文潮 + 增水情景带（如 0/0.5/1.0 m） | 验潮记录到位后升级 |
| 独立观测 | 宁明 2026-08（台风紫檀）：本地 GF-3 两期（8/6 灾前、8/24 近洪峰）+ 4 站水位（站基面，年份与央视报道吻合）；2024-09 摩羯：S1 目录可下载（Dataspace 账号已有），久隆有退水后期过境 | 现场水痕等补充 |

### 2. 垂直基准（回应 datum_offset_m）

`datum_offset_m` **继续为 null，不填猜测常数**（终稿硬规则）。可行获取路径按优先级：

1. **正式**：测绘控制点成果 / 水文站基面考证（当前不可得，保留为升级项）。
2. **公开可操作**：
   - 查证本地 DEM 的产品来源与垂直基准（ALOS AW3D30→EGM96 正高；GLO-30→EGM2008；SRTM→EGM96）；
   - DEM 间统一到 EGM2008：用公开大地水准面格网（PROJ grids：egm96_15 / EGM2008）计算，**按格网逐点算，不写全局常数**；
   - 1985 国家高程基准 ↔ EGM2008 的区域系统差（公开文献量级约 0.1–0.6 m，随地点变化）：无控制点时**用情景带（如 0 / ±0.3 m）做敏感性**，不采信单值。
3. **降级模式实用原则**：模型内部统一以所选 DEM 自身基准为基准；**只有引入外部绝对水位（站基面水位、潮位）时才需要换算**；验证优先使用相对指标（淹没范围 CSI、水位相对偏差），规避绝对高程偏差影响。

### 3. 结论等级约束

降级模式下全部产品标注**「研究性/情景性分析」**；河道型事件不得给出确定性防洪结论（对应终稿「计划状态」与第十五章）。终稿原阶段 0 门禁（授权数据质量）**未满足**，以本 ADR 的「降级门禁」替代推进：地形（本地 DEM，待查证）、驱动（ERA5）、独立观测（宁明 2024-08 本地 GF-3；S1 可下载）三要件**降级齐备**，阶段 1/2 可启动。

### 4. 已接受的代价

- ERA5 平滑局地强对流 → 洪峰过程可能偏低/偏钝，进入验证报告的驱动不确定性清单；
- 河道无断面 → 水深为条件性筛查（终稿 风险 R1 原文允许的降级）；
- 结论不得用于业务告警（终稿 0.1 条件更不可能满足）。
