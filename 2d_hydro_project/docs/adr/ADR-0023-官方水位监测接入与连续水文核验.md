# ADR-0023：官方水位监测接入、垂直基准对齐与连续水文核验体系

- **状态**：已接受（Accepted）。
- **日期**：2026-11-25
- **触发**：此前三案例验证仅依赖单景/双景 Sentinel-1 二值淹没范围（缺乏连续水位过程对照），且 `validate_guigang_s1.py` 仅硬编码两个单点水位诊断值。随着广西/广东官方水文渠道与本地站点档案接入能力建立，需规范化水位接入、垂直基准处理与多指标核验口径。
- **关联**：ADR-0004（垂直基准红线）、ADR-0017（ICESat-2 ATL13 基准探针）、ADR-0022（2024/2026 历史工况隔离）。

## 决策

1. **三通道合法接入与反混淆原则**：
   - 支持（1）站点 YAML 档案与官方公报归档 CSV/JSON、（2）Shapefile/DBF 站点资料（如 `宁明县水位站点信息.shp` 4 站实测）、（3）公开无加密 HTTP JSON 接口；
   - 若官方网页返回 `#FontTag` 字体加密或 JS 动态防护（如实测 `xxfb.mwr.cn` / `zwswj.com`），严格 fail-closed 记为 `protected_or_obfuscated`，**禁止任何绕过/破解操作**，引导通过数据开放平台授权接口或人工导出归档接入。
2. **垂直基准与 G7 保护纪律**：
   - 在站基面与工作 DEM 基准未联合平差闭合前（`datum_closed=False`），**严禁把未校准的 `NSE/RMSE` 绝对值写为精度结论**；
   - 统一采用**基准无关的相对涨水幅度 $\Delta H(t) = H(t) - H_{\text{base}}$** 与峰现时刻差 $\Delta T_{\text{peak}}$ 评估水文过程拟合优度，同时完整登记表观基准差（apparent offset）分布。
3. **双锚点虚拟水尺提取**：
   - 当站点坐标与 OSM 实测河道存在偏移时（如贵港暂定锚点与郁江主槽相距 ~2.5 km），同步提取 `raw_anchor` 与 `snapped_channel` 双口径序列，避免陆域高地掩盖真实河槽涨水信号。
4. **工况时空严格隔离（ADR-0022 延续）**：
   - 2026 年平陆运河通航后久隆站（K88+000）实测水位强制标注 `qc_flag=9` 与 `exclude_from_2024_validation=true`，严禁混入 2024-09 摩羯历史验证。

## 后果

- 实测接入宁明 4 站（含县城站、板祝站）并复算历史情景：闭东界情景 `scen_q6000_n100_100m_choff_eclosed` 在宁明县城站相对涨水 `NSE_rise` 从 0.810 提升至 **0.926**、峰现误差压降到 **+4.0 h**，量化证伪了东缘假排水短路。
- 为后续获取广西公共数据开放平台（`gxsjkf.dsjfzj.gxzf.gov.cn`）与“桂水文”逐时水位序列提供了开箱即用的 `.bdy` (`HVAR`/`QVAR`) 同化与自动化评估通道。
