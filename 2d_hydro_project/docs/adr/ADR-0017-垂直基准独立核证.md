# ADR-0017：垂直基准独立核证（ICESat-2 ATL13 / JRC GSW 探针）

- **状态**：已接受（Accepted）。计划 T09（成功标准 S5）预注册。
- **日期**：2026-11-22
- **触发**：G7 垂直基准未闭合（贵港站 43.09/44.00 m 报道水位与模型 apparent offset 两时点不一致，`validate_guigang_s1.py` 已判不得作 datum_offset）。方法来源：钟鸣 ICESat-2 洪泛区地形与坡度校正（10.1016/j.jhydrol.2026.136052）。
- **关联**：ADR-0004（降级模式与垂直基准红线）、ADR-0006（湿判据与切片口径）。

## 决策

### 1. 探针口径

- **量**：「DEM 表面 − ATL13 水面」系统差，逐轨统计（中位数 ± IQR）+ 汇总区间；**不得写死 datum_offset 常数**（该差含水深分量与基准差分量，只能收「有界估计」）。
- **水面段识别**：ATL13 沿轨水面高程，质量标志过滤（`quality` 置信位）；叠加 JRC GSW v1.4 occurrence ≥80% 常水像元掩膜圈定河道/常水区。
- **落格**：沿轨点经 UTM 变换取最近 dem.asc 格网；取该格 DEM 高程求差；格网 nodata 像元剔除。
- **坡度校正**：明江沿程坡降明显河段可选做（沿轨距离线性去趋势）；贵港平原段不做（坡降近零）。
- **覆盖门**：郁江+明江合计 ≥10 轨为「覆盖充分」；不足 → 降级「覆盖不足」，G7 维持「未闭合」（风险表兜底）。
- **留出纪律**（计划 §6.3）：分轨结果随机保留 ≥2 轨为独立复核集，不参与任何调参。

### 2. 数据通道与降级

- icepyx（BSD-3-Clause，仓库已核验）检索 NSIDC ATL13（2019–2026，bbox 内）；需 Earthdata 凭证。
- 凭证缺 → 探针记「数据不可得」，S5 记「未验证」；脚本与合成单测仍落地（计划 §6.4 纪律）。
- 媒体水位常数（43.09/44.00 m）维持「公开报道、站基面、G7 未闭合」标注，不因探针升级。

### 3. 禁止表述

- 不得将 offset 区间表述为「DEM 修正量」或直接改 dem.asc；
- 不得以 ATL13 少量轨次的偏态样本给出结论性基准差；
- 探针结果只入 `data/catalog/gx_datum_probe.json` 与报告的「有界估计」段落。
