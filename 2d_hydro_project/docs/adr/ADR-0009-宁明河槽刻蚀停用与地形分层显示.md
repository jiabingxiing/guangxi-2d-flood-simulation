# ADR-0009：宁明河槽刻蚀停用与地形分层显示

- **状态**：已接受（Accepted）
- **日期**：2026-10-28
- **触发**：用户比对可视化「DEM 高程」层与 ArcGIS 中的广西 DEM，发现前者存在规则长条，后者没有。

## 背景

1. 可视化 DEM 层数据源为各 run 目录的 `dem.asc`（`flood_visualization/src/floodviz/pipeline.py` 的 `_process_dem`），不是源 DEM 裁切件。
2. 宁明 `prep` 自 2026-10-24 起用「8/6 常水水体 → 贪心连通 → 同一行延伸至西缘 → 逐列线性刻蚀」生成河槽，共改 810 像元（8.10 km²）。
3. 审计实测（`data/catalog/dem_channel_audit.json`）：
   - 距最近常水像元 >250 m 的刻蚀像元占 64.0%，最远 2,759 m；
   - 刻蚀处原始高程中位数 128.0 m，>150 m 占 31.6%；
   - 最大下切 244.19 m；
   - 176/176 列刻蚀值为常值，渲染呈等宽竖条。
4. 代码注释声明依据为「域内 82–92 m 低带」，与上述输出矛盾。
5. 另发现上游点源位于网格东缘列（`col = W-1`），该列同时是 `FREE` 出流边界。四边 FREE 时 83.0% 的注入体积直接从东缘排出。

## 决策

1. **宁明 `--channel` 默认值改为 `off`**：不修改任何地形，`dem.asc` 等于 `dem_filled` 重采样结果。
2. **保留 `watermask` 与 `centerline` 两模式，但加硬约束**：
   - `watermask` 只取最大 4-连通水体组件，不跨组件跳接，不水平延伸至西缘；
   - `centerline` 必须提供外部中心线文件，缺失即退出，不回退到其它模式。
3. **刻蚀必须可审计**：任何非 `off` 模式在 `prep` 末尾自动调用 `dem_channel_audit`，`FAIL` 时删除 `dem.asc`、差异栅格与 run 参数并终止，不生成 `run.par`。
4. **审计门**（预注册，不得事后放宽）：距常水 >250 m 占比 >20%，或最大下切 >30 m，判 `FAIL`。
5. **既有 19 个宁明 run 全部记为 `FAIL`**，不重跑、不删除，作为历史证据保留。
6. **可视化拆分为三层**：
   - `terrain_source`：源 DEM 裁切件，标签「源 DEM（未修改）」，色带按观测 p1–p99 自适应；
   - `terrain_edit`：地形修改证据，仅有逐像元留痕时绘图，否则只列 meta 登记计数（`status=partial`）；
   - `dem`：改名「模型输入地形（含预处理修改）」，`note` 与 `modification_summary` 载明修改量。
7. **不改变边界条件**：东缘短路问题本轮只量化登记（`data/catalog/ningming_boundary_shortcut.json`），修改边界定义须另立 run 与 ADR。

## 后果

- 宁明既有验证结论的口径变化：
  - CSI 0.357、POD 0.773、FAR 0.602、面积偏比 1.94 建立在人造河槽之上，须标注为「含地形情境假设」，不得作为模型物理性能结论。
  - `E_mass` 达标不等于地形可出流：`nocut-v1` 的 `E_mass=2.93e-4` 达标，但 83% 注入量从东缘边界排出。
- `nocut-v1`（`--channel off`，q6000/n0.10/100 m）实测：
  - `E_mass = 2.93e-4`（PASS，`≤1e-3`）；
  - 湿面积 119.15 km²（阈值 0.05 m，`res.max` 口径）；
  - CSI 0.334 / POD 0.853 / FAR 0.645（旧口径，仅参考，不作优选依据）；
  - 站址 ±2 格水深 11.28 m，站址像元 0.015 m。
- 真实地形静态连通性预检：源高程 103.6 m 时连通域 110.67 km² 已触及 W/N/S 边界，无需壅高；但该连通为面状铺展，不是河槽形态。
- 宁明后续正式验证必须先解决两件事：河槽几何来源（断面资料或可核验中心线）与边界定义（注入口与出流口分离）。
