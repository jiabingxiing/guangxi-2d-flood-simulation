## 5. 账面判读（必须与数值一起写）

- `inf1e-6`：`Rain-(Inf+Evap)` = 2.153e+07 m³（无入渗基线 1.541e+08 m³，差 1.325e+08 m³ 即入渗损失）。
- `inf5e-6`：`Rain-(Inf+Evap)` = -4.888e+07 m³（无入渗基线 1.541e+08 m³，差 2.029e+08 m³ 即入渗损失）。
  - **该值为负**：入渗损失大于降雨总量，模型同时在扣减上游来水与初始蓄水。因此 `inf5e-6` 是**上限包络**，不是可接受率定值。

## 6. 可写 / 不可写

- 可写：标量入渗 0 → 1e-6 → 5e-6 m/s（0/3.6/18 mm/h）三档**预注册**情景已跑（三档在跑之前登记于计划，不是按 CSI 事后挑档），给出了面积/CSI/FAR 对损失量的敏感度；账目口径经受控算例验证（36 mm/h 雨 + 18 mm/h 入渗 → 末水深 18.0 mm，反算损失 17.5 mm）。
- 可写：入渗是本案例面积的**强杠杆**：面积偏比 1.94 → 1.51 → 0.92×，CSI 0.357 → 0.372 → 0.471，FAR 0.602 → 0.549 → 0.330；但 POD 同时 0.773 → 0.681 → 0.613 下降，说明“多排水”不是全面改善。
- 不可写：不得把 5e-6 档当作率定结果或推荐参数；不得称“喀斯特入渗率已确定”“分布式喀斯特入渗已建模”。该损失“全域均匀、仅非河道单元、无空间机制”，是**代理**。
- 后续：R6 定量需地质/观测依据（泉流量、水位退水曲线、示踪）；在有依据前，宁明面积偏差应同时报告 0 与 1e-6 两档，不得只报最好的一档。
