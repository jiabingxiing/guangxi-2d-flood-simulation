## 2. QA 发现（进入处理队列）

1. **宁明 0 值像元 644,490 个**（约 10%）：内陆无海面，疑为源 DEM NoData 空洞——阶段 1 续做空洞统计与填补策略（Priority-Flood 前先界定真实洼地，终稿 六.3）。
2. **久隆负值像元约 30%**（-38 m 起）：海面/水面负高程（RTC 类产品特征）——感潮建模前须界定海面高程处理；同时佐证 DEM 产品来源待查证（G7）。
3. 宁明「淹没范围」与「8月24日水体」两图层要素完全相同（7924 图斑/130.14 km²）——验证时需与 8/6 层做差得到「新增淹没」，不得直接当作净增淹没。
