# 广西二维洪涝可视化 standalone

请双击同目录的 `打开可视化.cmd`。

不要直接双击 `index.html`。

本目录包含完整 {{BUNDLE_ID}} 发布包：

- 久隆、宁明、贵港三地；
- 6 小时一帧的真实推演结果；
- 洪涝、DEM、SAR、光学图层；
- 地形分层：源 DEM（未修改）、地形修改证据、模型输入地形；
- float32 数值块与点查询；
- 页面静态资源和本地许可证。

启动器使用 Windows 自带 PowerShell，在 `127.0.0.1` 上提供本地网页服务。

> 本文件由 `scripts/sync_standalone.py` 从 `standalone/_launcher/README.md` 生成。
> 不要直接改本目录的副本；改模板后重新同步。
