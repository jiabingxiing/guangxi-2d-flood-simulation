# 发布授权与数据条款（floodviz 发布包）

本文件说明 **floodviz** 发布包内含内容的授权状态。它不替代各数据提供方的原始条款。

| 组件 | 版本 | 许可 | 说明 |

| Proj4js | 2.22.0 | MIT | 本地 vendor，原文见 `licenses/proj4-LICENSE.txt` |
| LISFLOOD-FP | 8.1.0 | **UNRESOLVED** | 模型求解器；Zenodo 元数据 gpl-2.0，官网页称 GPLv3 非商业，源码文件头为准；**本地未解决，不得外发** |

## 2. 数据

| 数据 | 类别 | 授权状态 | 约束 |
|---|---|---|---|
| 模型水深帧（`scen_*`） | 本项目计算结果 | 内部研究使用 | 研究性情景，不是业务预警；不得作为资产安全判据 |
| 广西 DEM（12.5 m） | 第三方 | **未闭合** | 来源/垂直基准/外发许可未确认，仅内部使用，不外发 |
| Sentinel-2 L2A（宁明 2026 / 贵港 2024） | 哥白尼计划 | 开放（自定义 Sentinel 条款） | 原始公开传播署名 `Copernicus Sentinel data [Year]`；修改后署名 `Contains modified Copernicus Sentinel data [Year]`；裁剪与遮云属修改；无质量担保 |
| Sentinel-1 GRD（久隆/贵港） | 哥白尼计划 | 同上 | 后向散射不是水深；必须显示实际覆盖足迹 |
| GF-3 SAR（宁明） | 第三方 | **待确认** | 仅作遥感背景，不外发原始数据 |
| Esri World Imagery / Street Map | Esri 服务 | 仅在线调用 | `exportTilesAllowed=false`；不得批量缓存或宣称离线授权；保留完整署名 |

## 3. 发布包内不包含

- 原始高程 TIFF（2.05 GB）、原始 RGB（4.7 GB）、原始 SAR 整景，均不入包。
- 模型网格 ASCII 原始帧（`res-*.wd`），只保留发布用 PNG 显示图与 float32 数值块。
- 任何凭证、`.env`、绝对源路径。

## 4. 使用者须知

1. 本页面展示的淹没范围为 **研究性情景**，不是业务预警，也不能作为资产级防洪结论。
2. 三地不是同一场洪水：久隆/贵港为 2024-09 摩羯事件，宁明为 2026-08 紫檀事件；页面不共用绝对时间轴。
3. 影像采集时间不随模拟时间轴改变；影像只在其真实获取时刻充当背景或观测证据。
4. 海域像元已从统计中剔除，但点查询返回模型真实值（海面已钳 0）。
