- 本项目当前仅作**内部研究/情景分析**，不得外发为业务成果或生产预警。
- 本地 DEM 来源/垂直基准（G7）未查证；WorldCover、Open-Meteo ERA5、Sentinel-1、GF-3 的许可/授权仍待逐项确认；LISFLOOD-FP 许可（Zenodo GPL-2.0 vs 官网 GPLv3 非商业表述）**UNRESOLVED**。

- RACI 按用户决定留空（G10），以 ADR/清单/测试/代码哈希留痕替代；独立审查仍缺。
- 结论：**合规门未通过**；在许可、G7、G12、站区资料和 RACI 补齐前，不进入生产/外发。
