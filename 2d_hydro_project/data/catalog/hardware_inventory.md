# 硬件与运行环境盘点（阶段 0）

- **盘点日期**：2026-10-24 ｜ **方法**：`wmic`（CPU/内存/OS）、`df -h`（磁盘）、`uv --version`
- **对照计划**：终稿头部「计算约束：本地纯 CPU、约 8C/16T」——**相符**

## 1. 实测清单

| 项目 | 实测值 | 与计划假设对照 / 影响 |
|---|---|---|
| CPU | AMD Ryzen 7 4800U，8 核 16 线程 | 与计划 8C/16T 一致；线程数须实测比较物理核/超线程，不预设最优（终稿 十） |
| 内存 | 16 GB（可用 15.37 GiB） | 硬约束：>1 百万网格算例须先基准；预计运行 + 输出缓冲不可超过约 12 GB |
| 系统 | Windows 10 家庭中文版 22H2 (19045) | LISFLOOD-FP 需确认 Windows 构建或经 WSL；WSL 本机可用（Ubuntu，数据在 D:\WSL\Ubuntu） |
| 磁盘 D: | 总 376 GB，**剩余 42 GB（90% 已用）** | **风险 R11**：单事件（DEM 瓦片 + S1 场景 + 中间件 + 输出）预计数十 GB，须预留 ≥100 GB（清理或外接盘） |
| TEMP/TMP | `D:\AppData\Local\Temp` | 与 D 盘同盘，加剧磁盘压力 |
| Python | PATH 默认 3.13.13；项目锁定 **3.12**（`.python-version`） | 避免版本漂移 |
| 包管理 | uv 0.11.15；全局 `uv.toml` → 阿里云镜像（default） | 直连可用（勿走失效的 schannel/curl 链路） |
| 网络 | 本地代理 `127.0.0.1:7897`（进程在用）；境外源基本可达，HEC-USACE 仅代理可达 | 详见 `data_reachability.md`；curl 在本机对 HTTPS 报吊销检查错误，脚本统一用 requests/uv |

## 2. 规模可行性初判（依终稿 1.2 网格量表）

| 算例 | 单元数（理论） | 本机初判 |
|---|---:|---|
| 久隆 10–25 km² @12.5 m | 0.064–0.16 百万 | 可行（仍须实测内存/耗时） |
| 宁明 100–300 km² @25 m | 0.16–0.48 百万 | 可行性较高，先做敏感性试验 |
| 宁明 @12.5 m | 0.64–1.92 百万 | 需基准实测，可能触内存上限 |
| 贵港区域 1000–2000 km² @30 m | 1.11–2.22 百万 | 需基准实测；必要时收缩水力域 |
| 任意 @5 m 大范围 | ≥40 百万 | 不采用（终稿 1.2） |

**结论**：CPU 符合计划假设；内存与磁盘是两个硬约束。阶段 2 基准测试必须实测峰值内存与磁盘输出量，再定时效目标（终稿 0.2「不预设性能」）。
