# 久隆水动力推演效果改进实施计划

> 版本：v3.0（2026-10-31）  
> 状态：实施前审阅定版草案  
> 适用案例：钦州久隆，2024-09 摩羯情景  
> 当前模式：ADR-0004 公开数据降级、情景级、非业务预警  
> 相关决策：ADR-0004、ADR-0006、ADR-0007、ADR-0008；ADR-0010 待建  
> 原文件中的 v1.0、v1.1、v2.0 方案已合并。本文件是后续实施的唯一计划基线。

## 执行摘要

当前久隆结果的主要问题不是单一“渲染噪点”，而是数据、网格、地形预处理、产流假设、排水边界和展示口径共同作用的结果。现有证据已确认以下事实：

- 当前生产基线是 `scen_free_200m` 等 **200 m 网格**。100 m 仅为敏感性试验，不能作为当前生产阈值的默认尺度。
- 200 m 久隆基线湿面积约 263.24 km²；100 m 敏感性试验湿面积约 271.01 km²，最大水深和站址邻域结果也有明显差异。分辨率变化会改变“一个斑块”的物理面积和水深采样，直接套用 100 m 规则会失真。
- 退水验证已发现，模型 09-10 至 09-17 湿面积增加 27.68 km²，而 S1 退水后水体约 12.2 km²。该证据支持“无排水网络、边界和延长降雨共同造成退水异常”的判断，但不支持把后处理滤波当作物理修复。
- 久隆负值 DEM 约 319.5 km²，而 S1 常水仅约 11 km²。约 96% 负值不能直接视为海面。任何负值修复必须先分辨无效值、真实水体和基准/产品异常。
- 现有部分情景为 `FAIL-EXPLAINED`，不计质量门通过。计划不能写“全量质量门通过”。

本计划采用六阶段路线：

1. **Phase 0：事实冻结、分辨率决策和根因诊断**；
2. **Phase 1：只读展示质控，快速改善观感并可回滚**；
3. **Phase 2：DEM 分层和选择性水文调理**；
4. **Phase 3：降雨损失与产流敏感性试验**；
5. **Phase 4：排水网络、边界和结构表达治理**；
6. **Phase 5：独立证据、回归、ADR 和发布定版**。

Phase 1 只能生成带有 `not_physical_recalculation=true` 标记的展示派生层。只有 Phase 2–4 经过授权、质量门和新 run tag 后，才可产生物理候选结果。

## 1. 项目概述与目标

### 1.1 目标

- 定量解释孤立点状斑块、规则几何色块和退水不合理的成因。
- 先提供不覆盖原始结果的展示治理层。
- 为物理重构建立数据分层、算法边界、试验矩阵和质量门。
- 对每项结论标注“已证实、强证据、假设、未测、FAIL-EXPLAINED”。
- 保持项目的情景级定位，不升级为确定性防洪、业务告警或资产级判据。

### 1.2 当前事实边界

| 维度 | 当前事实 | 影响 |
|---|---|---|
| 生产网格 | 久隆实际 200 m；100 m 为敏感性试验 | 阈值和比较必须先按 200 m 冻结 |
| 降雨 | ERA5 2024-09-05 至 09-16 累计 227.7 mm | 不是站点实测雨量 |
| 上游注入 | 无干流注入 | 不能借用宁明/贵港的河流注入逻辑 |
| 下游边界 | FREE、Z=0、Z=0.5、Z=1.0 情景 | 无授权潮位过程，结论为情景级 |
| DEM | 12.5 m 源数据经处理后用于 200 m 模型 | 负值来源和垂直基准仍有缺口 |
| 独立观测 | 久隆仅有灾前/退水后 S1 弱证据 | CSI、NSE 和水深精度当前未形成独立门 |
| 站址 | 精确坐标和站区排水资料待确认 | 禁止资产级水深判据 |
| 质量门 | 现有部分 run 为 FAIL-EXPLAINED | 不得写成全量 PASS |

### 1.3 不在范围内

- 不修改 `2d_hydro_project/models/`。
- 不覆盖任何已有 `res.mass` 的 run 目录。
- 不在未授权时重跑 `lisflood.exe`。
- 不把展示滤波后的水深称为新的物理模拟结果。
- 不把 100 m 敏感性结果当成 200 m 生产结果。
- 不把没有观测支持的 NSE、R²、20% 水深误差或 15% 面积误差写成当前硬门。

### 1.4 分辨率决策是前置门禁

旁路观察指出的核心问题成立：当前生产尺度是 200 m，而原计划多处使用 100 m 规则。对同一规则：

- 100 m 网格 1 格 = 10,000 m² = 0.01 km²；
- 200 m 网格 1 格 = 40,000 m² = 0.04 km²；
- 100 m 的 4 格 = 0.04 km²；200 m 的 4 格 = 0.16 km²；
- 100 m 的 9 格 = 0.09 km²；200 m 的 9 格 = 0.36 km²。

因此“4/9 像元”不是跨分辨率稳定的物理阈值。若在 200 m 结果上直接使用 100 m 规则，会把四倍面积的斑块误判为同一类对象，并可能删除真实积水。Phase 0 必须先完成以下二选一：

| 方案 | 适用条件 | 结果 |
|---|---|---|
| A：按 200 m 生产基线治理 | 当前目标是快速改善现有交付产品 | 所有展示阈值按 200 m 换算；100 m 仅作敏感性参照；推荐 |
| B：批准 100 m 或更细重跑后治理 | 有计算资源、输入可信度和用户授权 | 先完成重跑、质量门和分辨率收敛，再冻结 100 m 阈值 |

在用户明确选择前，计划只允许做分辨率无关的诊断，不允许冻结 4/9 像元等过滤阈值，也不允许把 100 m 结果切换为默认生产层。默认按方案 A 编制 Phase 1。

## 2. 开源调研与借鉴方案

本项目只采用已核验或可在本地证据中复核的算法原则，不把未经核验的外部阈值写成强制标准。

### 2.1 检索矩阵与推荐资源

| 平台 | 检索词 | 筛选结论 |
|---|---|---|
| GitHub | `hydrology priority flood raster` | 采用成熟栅格水文分析实现，先做本地合成算例 |
| GitHub | `connected components raster python` | 采用连通域和时序统计思路，不直接复用展示阈值 |
| GitHub | `LISFLOOD-FP` | 保持当前上游模型定版，不修改模型源码 |
| GitHub | `rasterio` | 沿用项目现有栅格读写与元数据处理能力 |

- 本项目采用已有 LISFLOOD-FP 8.1.0 冻结构建，本计划不引用未核验的上游镜像仓库地址。
- `https://github.com/rasterio/rasterio`：仓库已核验；栅格 I/O 和元数据处理。许可字段为 `NOASSERTION`，须在引入依赖前复核许可证文件。
- `https://github.com/scikit-image/scikit-image`：仓库已核验；连通域分析候选组件。许可字段为 `NOASSERTION`，须在引入依赖前复核许可证文件。
- `https://github.com/numpy/numpy`：仓库已核验；数组统计、掩膜和体积账目计算。许可字段为 `NOASSERTION`，须在引入依赖前复核许可证文件。

以上资源只提供工程组件或分析方法。许可证和仓库状态须在实施前重新核验；核验失败的资源不得进入推荐实施清单。

### 2.2 可借鉴原则

| 主题 | 可借鉴原则 | 本项目边界 |
|---|---|---|
| Rain-on-Grid | 地形、排水结构、损失参数和观测校准共同决定可信度 | 不把展示滤波当作模型校准 |
| DEM 水文处理 | Priority-Flood 可用于水文分析和局部假坑处理 | 不默认替换水动力 DEM，不填平真实洼地 |
| 地形修复 | 先确认无效值，再做局部、可审计修复 | 不用全域 Spline/IDW 推断未知排水路径 |
| 直接降雨损失 | 可用标量损失、初损/持续损失或入渗模型做敏感性 | WorldCover 不能单独决定参数 |
| 流网表达 | 可信中心线、断面、影像或现场资料优先 | 不把 D8 廊道自动当作真实沟渠 |
| 结果质控 | 采用空间、时间、深度、连通性联合规则 | 阈值须按实际网格和本地试验冻结 |

### 2.3 明确禁止的表述

- 不写“ARR 2019 强制规定 0.1 m、0.3 m、500–2000 m² 或 0.02 m²/s 通用滤波阈值”，除非逐条核验原文用途和适用条件。
- 不把水深乘速度的安全评估指标直接改写成普适噪点过滤规则。
- 不写“Priority-Flood 不会制造平坦面”。填洼后仍需检查平坦面和水力连通性。
- 不写“红壤地区初期必然吸收 30–50 mm”。该范围只能作为待试验假设。
- 不写“过滤率达到 90% 即证明模型正确”。过滤率只能是展示质控指标。

### 2.4 研究结论的证据等级

- **E1：仓库实测/可复现**：已有 run、JSON、质量账目和脚本可复核。
- **E2：强证据**：多项现有证据一致，但缺少独立观测。
- **E3：候选假设**：需要试验或外部数据确认。
- **E4：未测**：当前没有足够数据，不得给出数值结论。

## 3. 系统架构与算法设计

### 3.1 数据流

```text
RAW DEM / ERA5 / S1 / 配置
        |
        v
Phase 0 事实冻结与诊断
        |
        +--> display_qc（只读展示派生层，不改物理结果）
        |
        +--> DEM_REPAIRED / DEM_HYDRO / DEM_HYDRAULIC 候选
                    |
                    +--> 产流敏感性 --> 排水/边界候选 --> 新 run
                                      |
                                      v
                              质量门与独立证据
                                      |
                                      v
                             发布与 ADR 定版
```

### 3.2 四层 DEM 契约

| 层 | 用途 | 允许操作 | 必须记录 |
|---|---|---|---|
| `DEM_RAW` | 原始归档 | 不修改 | 来源、哈希、NoData、基准 |
| `DEM_REPAIRED` | 修复确认无效值 | 仅局部、有来源 | 像元差异、修复原因、不确定度 |
| `DEM_HYDRO` | D8、汇流、连通分析 | 选择性填洼 | 填洼区域、体积、流向变化 |
| `DEM_HYDRAULIC` | 水动力求解 | 保留真实洼地；按资料修结构 | 修改清单、版本、回滚路径 |

`DEM_HYDRO` 不得直接替代 `DEM_HYDRAULIC`。任何替代必须经过独立试验和用户批准。

### 3.3 Phase 1 展示质控算法

展示层名称使用 `display_qc` 或 `presentation_filtered`，禁止使用“校准”“真实淹没”。规则顺序如下：

1. 区分 nodata、海面、0 水深和有效浅水。
2. 以实际网格面积计算斑块面积。200 m 默认网格的单元面积按栅格元数据读取，不写死。
3. 统计每个斑块的面积、最大/均值/分位水深、出现帧数、连续帧数、与候选主汇流区的距离。
4. 小且短暂、孤立、浅水、无可信地形/包络支持的斑块进入过滤候选。
5. 与主水体连通、持续存在、深度较大、位于可信排水路径或对退水有贡献的斑块豁免。
6. 输出 A/B/C 三档参数。参数必须在处理前登记，不能按结果截图事后选择。
7. 每帧写出被过滤像元、面积、体积、斑块数和原因码。

**参数冻结规则：**

- Phase 0 前不冻结 4/9 像元阈值。
- 若按方案 A，优先使用物理面积阈值 + 持续性阈值，并把像元数作为随网格变化的换算结果。
- 若必须使用像元数，公式为 `n_cells = ceil(area_threshold / cell_area)`，并在审计文件中写入网格分辨率和实际面积。
- 水深阈值属于项目候选参数，不自动归因于国际规范。
- 任何阈值导致重要区域面积或体积变化超过预注册告警值时，只能作为诊断层，不得默认发布。

### 3.4 分辨率比较方法

跨分辨率比较必须同时报告：

- 物理面积和斑块数量；
- 统一物理半径内的最大/分位水深；
- 总蓄水量、出口量和降雨量；
- 同一事件窗口和同一输出时间；
- 同一河沟/边界参数化方式；
- 输入地形版本和参数哈希。

不能只比较“斑块个数”或“像元百分比”。200 m 方案和 100 m 方案必须使用同一物理面积阈值做敏感性对照。

### 3.5 物理重构原则

- 负值 DEM：先判定无效值、真实水体和基准问题；不做全域统一钳位。
- Priority-Flood：优先用于 `DEM_HYDRO`；仅对确认的数字微坑试验。
- 最小坡度：不默认施加全域 0.0005；只有在有可信流线和敏感性证据时局部试验。
- 入渗：先跑现状零入渗，再跑预注册的标量损失和参数范围；SCS-CN、Horton、Green-Ampt 不得直接选单值生产。
- 排水网络：仅使用可信中心线、影像、断面或现场资料；D8 仅是候选线索。
- 刻蚀：不采用全域固定 0.5–1.5 m。每段需有来源、范围、深度上限、水位差和回滚栅格。
- 结构：遵守 ADR-0008，未经再验证不得启用 bridge/orifice。

## 5. 分阶段开发计划

|---|---|---|---|---|---|

### Phase 0：事实冻结、分辨率决策和根因诊断

**目的：** 在任何治理或重跑前统一尺度口径。

**任务：**

1. 固定 200 m 生产基线、100 m 敏感性基线及其 run manifest。
2. 复核栅格元数据、实际单元面积、输出时间和事件窗口。
3. 统计全部帧的斑块面积、深度、体积、持续性和连通关系。
4. 叠合 BFS/负值处理区与几何色块。
5. 复核 12.5→100/200 m 重采样对坡度、局部坑洼、D8 和出口的影响。
6. 对负值 DEM 做水体、无效值和基准异常分类。
7. 对退水期水量、湿面积、降雨、出口和边界逐项对账。
8. 形成方案 A/B 分辨率决策单。

**产出：** `diagnostics/jiulong/` 下的快照、报告、CSV、栅格、哈希清单。

**门禁：** 所有结论写证据等级；方案 A 或 B 未确认前不冻结展示阈值。

### Phase 1：200 m 基线的只读展示治理

**前置：** 方案 A 已确认，或方案 B 已完成新分辨率质量门。

**任务：**

1. 开发时空斑块分析和展示质控脚本。
2. 按真实单元面积计算阈值，生成 A/B/C 参数对照。
3. 生成独立 `display_qc` 目录，不修改 raw run。
4. 输出逐帧审计、参数哈希、体积变化和抽样斑块清单。
5. 在前端保留 raw、display_qc、diagnostic overlay 三层。

**验收：**

- raw 文件哈希前后一致；
- display_qc 具有 `derived_from` 和 `not_physical_recalculation=true`；
- 阈值、网格和时间口径完整；
- 不以视觉效果单独通过；
- 超过预注册体积/面积影响阈值时自动阻止默认发布。

### Phase 2：DEM 分层与选择性调理

**前置：** Phase 0 D1、D2 完成。

**任务：** 生成四层 DEM；修复确认无效值；在 `DEM_HYDRO` 上试验局部填洼；评估蓄水容量、坡度、流向和出口变化。

**验收：** 修改区域、体积和最大改变量可追溯；合成地形测试通过；真实洼地未被无证据抹除；未授权时只产生候选输入。

### Phase 3：降雨损失与产流敏感性

**前置：** Phase 2 只需完成输入契约，不要求先切换正式 DEM。

**任务：** 运行零入渗、标量损失、初损+持续损失和条件允许的入渗模型；预注册低/中/高参数；核算总雨量、损失、净雨、蓄水和出流。

**验收：** 受控算例质量账目通过；净雨非负；损失不超过可用水量；无观测时只标为敏感性情景。

### Phase 4：排水、边界和结构治理

**前置：** 用户提供或确认排水/潮位/下游断面资料，或明确接受候选情景。

**任务：** 先核查边界与重复计量；建立候选排水网络；必要时对有来源河段有限刻蚀；审计退水水量；按 ADR-0008 表达结构。

**验收：** 逐项对账；通道改动可回滚；退水异常若未消除必须给出原因，不得以滤波掩盖。

### Phase 5：独立证据、回归和定版

**任务：** 检索同事件影像；按时刻和覆盖范围对齐；必要时沿用 S1 `WEAK`；汇总 raw/display_qc/物理候选；更新 ADR-0010、`execution_status.md` 和前端配置。

**验收：**

- 输入、代码、参数和输出 manifest 完整；
- `g15_mass_recheck.py` 状态逐 run 列明 PASS、FAIL-EXPLAINED 或 FAIL；
- 有观测才计算 CSI/POD/FAR/NSE/R²；没有则标“未测”；
- 旧结果保留，默认切换有审批记录；
- 发布包通过 inventory、validate 和测试。

## 6. 数据与模型训练策略

本项目不是机器学习训练项目。这里的“模型策略”指物理参数试验和证据管理。

### 6.1 数据分级

| 数据 | 当前状态 | 使用方式 |
|---|---|---|
| 12.5 m DEM | 来源/垂直基准未完全确认 | RAW 归档、误差诊断、候选修复 |
| 200 m 生产输出 | 已有且可复现 | 当前展示治理基线 |
| 100 m 输出 | 敏感性试验 | 仅分辨率对照 |
| ERA5 降雨 | 公开降级驱动 | 事件输入，不视为站测 |
| S1 | 灾前/退水后，提取有限制 | WEAK 趋势参照 |
| WorldCover | 土地覆盖先验 | 不能单独确定入渗 |
| 排水/潮位/站址资料 | 多项待授权 | 作为阻塞项登记 |

### 6.2 参数试验矩阵

所有物理参数在运行前登记低、中、高档。每档记录单位、来源、适用范围、置信度和预期影响。禁止根据结果事后挑选“最优”参数。

### 6.3 分辨率试验矩阵

最小矩阵包括：200 m 当前基线、100 m 已有敏感性、统一物理面积阈值对照。若选择方案 B，再增加新分辨率的完整质量门、计算成本、输出时间和水量账目。没有完成同一物理口径换算前，不比较单纯像元数。

### 6.4 划分与标注策略

模型参数情景按输入版本和事件时间分组，不把同一事件的相邻帧拆成独立验证样本，避免时间泄漏。当前没有训练集和人工标签集；诊断斑块标注由规则生成并抽样人工复核，复核结果只作错误分析，不作为独立真值。数据不足时不开展监督训练，相关性能指标标记“未测”。

### 6.5 数据不足时的处理

- 无连续观测：相关指标标“未测”。
- 无可靠排水线：只生成候选网络，不切换生产。
- 无垂直基准：使用相对指标和情景带，不填猜测常数。
- 无授权数据：维持 ADR-0004 降级模式，不扩大结论等级。

## 8. 风险与后续优化方向

| 风险 | 影响 | 缓解 |
|---|---|---|
| 200 m 上直接套用 100 m 阈值 | 高 | Phase 0 分辨率门禁；按物理面积换算 |
| 滤波误删真实积水 | 高 | raw 保留、持续性/连通性豁免、三档预注册 |
| 展示质控被误读为物理修复 | 高 | `display_qc` 命名、派生标记、双层展示 |
| Priority-Flood 改掉真实洼地 | 高 | DEM 分层、局部试验、容量审计 |
| 固定刻蚀制造假水道 | 高 | 资料来源、深度上限、逐段审计、回滚 |
| 入渗参数无本地率定 | 中 | 敏感性集合、置信度、受控算例 |
| S1 证据不足 | 中 | 保持 WEAK，不升级验证等级 |
| 站址坐标或基准错误 | 高 | 业务核证前不做资产级判据 |
| 运行覆盖旧成果 | 高 | 新 run tag；含 `res.mass` 即退出 |
| 200 m 物理能力不足 | 中 | 方案 B 独立审批；比较计算成本和收益 |

后续优化优先级：

1. 取得站址精确坐标和下游控制断面资料；
2. 补充久隆事件窗口遥感或现场水痕；
3. 建立可信排水网络和结构资料；
4. 在用户批准后进行 100 m 或更细分辨率完整重跑；
5. 对授权雨量、潮位和水位过程进行独立验证。

## 9. 推荐技术栈与工具链

- 模型：LISFLOOD-FP 8.1.0，遵守 ADR-0008，不修改上游源码。
- Python：项目现有 `uv` 环境；运行前设置 `PYTHONUTF8=1`。
- 栅格：沿用现有 GDAL/rasterio/numpy/scipy 能力；所有栅格写出 CRS、分辨率、nodata 和哈希。
- 斑块分析：8 邻域连通域、时序追踪、物理面积和体积统计。
- 追溯：输入 manifest、代码 manifest、参数 manifest、run tag、JSON 审计。
- 发布：沿用 `flood_visualization` 的 inventory、validate、pytest 和双 bundle 回滚约束。
- 文档：`execution_status.md` 是执行状态 SSOT；物理决策进入 ADR-0010。

### 9.1 里程碑与决策门

| 里程碑 | 产出 | 决策门 |
|---|---|---|
| M0 | 事实清单和本计划 | 200 m/100 m 方案选择 |
| M1 | Phase 0 诊断包 | 才能冻结展示阈值 |
| M2 | display_qc 派生层 | raw 不变且可回滚 |
| M3 | DEM/边界候选 | 是否授权物理重跑 |
| M4 | 入渗/排水敏感性 | 是否具备物理改进证据 |
| M5 | 独立证据报告 | 有观测才启用精度指标 |
| M6 | 回归、ADR、发布 | 才能切换默认层 |

### 9.2 回滚规则

- 展示层：切回 raw，不删除派生产物。
- 物理候选：不覆盖旧 run，不自动切换默认 run。
- 门禁失败：保留证据，标记 FAIL 或 FAIL-EXPLAINED，不通过删除目录解决。

### 9.3 当前需要用户确认的事项

1. **推荐：** 先按 200 m 生产基线完成 Phase 0 和展示治理；100 m 仅作为敏感性对照。
2. 是否批准 100 m 或更细分辨率的完整物理重跑；批准前不把 100 m 结果升级为生产基线。
3. 是否允许使用 display_qc 作为前端默认展示层；raw 保留为科研诊断层。
4. 是否能提供站址坐标、排水网络、潮位/水位和事件窗口观测资料。
5. 是否接受当前久隆独立验证状态为 `WEAK/未测`，不设置 NSE、R² 和水深误差硬门。

本计划的首要结论是：**先统一网格口径，再冻结滤波阈值和验收门槛。当前推荐以 200 m 为治理基线，100 m 只作敏感性试验；只有完成授权重跑、质量门和分辨率收敛后，才可改变该基线。**
