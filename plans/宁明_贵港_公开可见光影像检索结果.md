## 4. 获取途径和许可

1. [AWS Open Data Sentinel-2 COG](<https://registry.opendata.aws/sentinel-2-l2a-cogs/>)：公开档案与免费 Earth Search 检索。上表 HTTPS 资产本次不带账号或 token 即可分段读取。
2. [Copernicus Sentinel-2 官方介绍](<https://dataspace.copernicus.eu/explore-data/data-collections/sentinel-data/sentinel-2>)：数据免费面向公众、科研及商业用户。
3. [Copernicus Data Space 条款](<https://dataspace.copernicus.eu/terms-and-conditions>)：Sentinel 数据按专门法律声明开放；其他门户内容另有版权限制，不能混淆。官方门户访问数据需注册，AWS 本次匿名路径不需要。
4. [现行 Sentinel 法律声明](<https://sentinels.copernicus.eu/documents/247904/690755/Sentinel_Data_Legal_Notice>)已核验HTTP 200并保存[许可PDF](<visualization_research/Sentinel_Data_Legal_Notice.pdf>)。允许合法复制、传播、修改和与其他数据组合。原始数据公开传播注明 `Copernicus Sentinel data [Year]`；修改后注明 `Contains modified Copernicus Sentinel data [Year]`。宁明写2026，贵港写2024。
5. STAC 的 `license=proprietary` 指向自定义Sentinel条款，不表示不能下载，也不能改称MIT/CC-BY。STAC旧ESA链接本次失败，以上现行Copernicus链接已通过。数据不保证质量或适用性；源数据开放不等于本地网络、计算和存储没有成本。
6. CDSE原生产品下载须注册并获取OAuth token；AWS上表公开HTTPS本次无需账号。两条下载路线的账号条件不得混用。

## 5. 网页接入要求

图层状态必须按案例登记：`remote_verified`（远端可读）、`local_unchecked`（本地未验）、`ready`（通过发布质检）、`partial`（部分覆盖）、`missing`（未提供）、`failed`（加载失败）。只有 `ready/partial` 可以启用开关；其余禁用并显示原因。

宁明、贵港当前均为 `remote_verified`，不是本地已导入。久隆虽有本地 RGB，也只有部分模型范围覆盖；时间是 2026 年影像，不能当 2024 年模型事件同期观测。

实施顺序：下载/裁剪 → SCL云影与有效掩膜 → 人工目视核对 → 授权和署名登记 → 生成瓦片/足迹 → 状态转 ready/partial。遮云区域显示透明和足迹边界，不用平滑填充冒充观测。
