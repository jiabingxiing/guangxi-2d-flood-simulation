## 二、必须修改的问题（否则易在工程中翻车）

### 1. 求解器定位必须二选一，禁止“双轨混写”

文档中同时出现：

- 推荐 **LISFLOOD-FP 8.x**（CLI、C/C++、OpenMP）
- 又给出完整 **Numba 局部惯性引擎**（`local_inertia_engine.py`）

二者不可在同一阶段并列为主力。

**完善写法建议**：

```text
主力求解器：官方 LISFLOOD-FP（或经团队验证的稳定 fork）
  - 输入：Hydro-DEM、manning.tif、雨量/边界时程
  - 输出：水深 GeoTIFF / 二进制，再转 NetCDF
对照/研究用：自研 Numba Local Inertia（仅用于小域算法验证、CFL/守恒测试）
禁止：第一阶段用未充分验证的自研引擎直接对标 SAR 验收
```

理由：

- 局部惯性格式在干湿边界、摩擦限制、子网格河道、数值稳定性上有大量工程细节；
- 8C/16T 上官方 OpenMP 实现通常更稳、更省调试时间；
- 自研代码中 `update_flux_local_inertia` 目前**只完整写了 x 向**，y 向未对称实现，且边界通量、干湿切换、入流分配均未接入，**不能直接用于生产推演**。

### 2. DEM 水文校正流水线需从“演示级”升到“可验收级”

当前四步法方向正确，但实现只有简单“缓冲带下挖固定深度”，在喀斯特宽谷（宁明）与平原河网（贵港）上风险很高。

**建议标准流水线（可写进第四节）**：

1. **投影与裁剪对齐**：统一 UTM（久隆 49N，贵港/宁明 48N）、与目标网格像元对齐（避免半像素偏移）。
2. **Bare-earth 优先**：优先 FABDEM / 已去建筑树冠产品；若仅有 DSM，再做滤波，并**显式记录“未完全去建筑”的不确定性**。
3. **填洼**：Priority-Flood / 带阈值填洼（不要无条件全填，保留真实湖库洼地）。
4. **河网提取与主槽识别**：用 HydroSHEDS / MERIT Hydro / 本地矢量水系做拓扑检查，区分主槽与沟渠。
5. **Stream Burning（分级）**：
   - 主槽：深刻（结合断面或经验深度剖面，而非常数 4 m）；
   - 支沟：浅刻或仅保证连通；
   - 有断面处：用实测断面控制河底高程。
6. **障碍物抬升**：堤顶、路基、变电站围墙/地坪——**抬高**而非下挖；桥涵可局部降低。
7. **连通性与流向检查**：填洼后流向、累积流量、出口是否合理；对久隆近海要检查感潮段连通。

**代码层面**：现有 `burn_stream_bathymetry` 可保留为“快速版”，另增：

- `fill_sinks_priority_flood`
- `burn_with_cross_sections`（断面控制）
- `raise_barriers`（堤/墙）
- 单元测试：主槽是否形成连续低谷、出口是否连通、水量能否到达下游边界。

### 3. 降雨与边界的“空间化”不足

- Open-Meteo 点雨量 + 3×3 平均：适合久隆小流域快速试验，**不适合宁明/贵港**面雨型差异大的事件。
- 入流按边界像元宽度线性分配：合理起点，但需说明断面法向、堤顶溢流、多汊分流。

**完善建议**：

| 阶段 | 降水驱动                                      | 上游边界                           |
| ---- | --------------------------------------------- | ---------------------------------- |
| 久隆 | 站点/Open-Meteo 或 ERA5 面平均 + 可选空间插值 | 小流域可雨量驱动为主，河道边界为辅 |
| 宁明 | ERA5-Land / GPM 格点雨量场裁剪到网格          | 明江控制站 Q(t) + 区间产流         |
| 贵港 | 格点雨量 + 流域面雨量校正                     | 郁江干流大流量过程线，必须断面分配 |

并补充：**时间步与模型输出步对齐**（如模型 10–60 s 内步，输出 15 min/1 h 与 SAR 过境时刻插值）。

### 4. 第三阶段 Nested Grid 缺少“可执行定义”

“30 m + 5 m 嵌套”目前只有目标，没有：

- 嵌套方式（单向/双向、时间插值、通量守恒接口）
- 粗细网格边界位置（沿河道还是行政界）
- 久隆/宁明成果如何迁移为贵港子域
- 8C/16T 上内存与墙钟时间预估

**建议在第八章增加最小可执行方案**，例如：

```text
贵港第一刀：
  - 全域 30–50 m 粗网格（或分区）跑通干流漫滩趋势
  - 变电站/关键堤段 5–12.5 m 子域，边界由粗网格水位/流量驱动（单向嵌套优先）
  - 双向嵌套留到算力与接口验证之后
```

## 三、强烈建议完善的内容

### 1. 数据源可达性与合规（补一小节）

| 数据                      | 风险                                     | 建议                                                           |
| ------------------------- | ---------------------------------------- | -------------------------------------------------------------- |
| 广西水文站实时/历史过程线 | 公开网多为实时摘要，历史精细过程常需申请 | 写明“项目组已获取/待申请”，并备选用公开洪水报告数字化        |
| 河道大断面                | 核心瓶颈                                 | 无断面时用“经验河深 + 河宽 + 比降”敏感性分析，并降低验收期望 |
| 变电站地坪/围墙           | 内部图纸                                 | 单独权限与脱敏处理                                             |
| Sentinel-1                | 可达性好                                 | 固定 ASF / Copernicus 下载脚本与轨道、升降轨、极化选择规范     |
| FABDEM / GLO-30           | 好                                       | 久隆核心区优先更高精度（若有 1–5 m 航测/测绘成果更好）        |

### 2. 案例事件选择（目前缺失）

三阶段都应**先锁定 1–2 场历史洪水**，再谈网格与模型：

- 有水文站洪峰过程；
- 有尽量同步的 SAR 过境（灾中或刚退后）；
- 尽量有灾情点（道路中断、站区进水等）做定性校核。

没有“事件清单”，SAR 对账与 CSI 门禁无法落地。

### 3. 曼宁糙率与率定策略

`LULC_TO_MANNING` 表可作为初值，但必须写明：

- 河道主槽与漫滩分区分值（不要只靠 WorldCover）；
- 率定参数维数控制（例如仅调 2–4 类 n，避免过拟合）；
- 率定用一场、验证用另一场或另一时相 SAR。

### 4. 纯 CPU 性能预期（写进验收，避免拍脑袋）

在 8C/16T 上给出**量级估算表**（可后补实测）：

| 区域     | 面积      | 分辨率 | 约网格数 | 72 h 洪水（量级）              |
| -------- | --------- | ------ | -------- | ------------------------------ |
| 久隆     | 20 km²   | 10 m   | ~2e5     | 分钟–数十分钟级（成熟求解器） |
| 宁明     | 200 km²  | 20 m   | ~5e5     | 小时级                         |
| 贵港全域 | 1500 km² | 30 m   | ~1.7e6   | 数小时；5 m 全域则不可接受     |

强调：**网格数、输出频率、是否开子网格河道**对耗时影响极大。

### 5. 自研 Numba 代码若保留，需补全与门禁

若保留研究引擎，至少补：

- x/y 双向对称通量；
- 摩擦项与 `h_flow` 限制的文献一致形式（Bates et al.）；
- CFL / 自适应 `dt`；
- 开边界、闭边界、入流像元；
- 全局水量守恒诊断每 N 步输出；
- 与 LISFLOOD-FP 同输入小域对比（最大水深、峰现时间）。

当前片段仅作示意，**不宜出现在“生产级实现路线图”标题下而不加“示意”标注**。

### 6. SAR 验证再补三点

- **时间对齐**：模拟输出插值到 SAR 过境 UTC，再转当地时；
- **几何对齐**：同一网格、同一 nodata、同一投影；
- **排除掩膜**：林地、城市强散射、雷达阴影/叠掩；久隆近海注意潮位与水体识别混淆。

CSI 0.65–0.85 作为目标合理，但应区分“开阔平原”与“植被/建成区”。
